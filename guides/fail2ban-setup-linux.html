Fail2ban — Block Brute Force Attacks

Fail2ban monitors log files for repeated failed authentication attempts and temporarily bans the offending IP using firewall rules. Essential for any internet-facing Linux server with SSH open.

Install

sudo apt install fail2ban -y      # Ubuntu/Debian
sudo dnf install fail2ban -y      # Fedora/RHEL
sudo pacman -S fail2ban           # Arch

sudo systemctl enable --now fail2ban

Configuration

Never edit /etc/fail2ban/jail.conf directly — it gets overwritten on updates. Create a local override:

sudo cp /etc/fail2ban/jail.conf /etc/fail2ban/jail.local
sudo nano /etc/fail2ban/jail.local

Key settings in [DEFAULT]:

[DEFAULT]
bantime  = 1h        # ban duration (use -1 for permanent)
findtime = 10m       # window to count failures
maxretry = 5         # failures before ban
banaction = iptables-multiport   # or nftables on newer systems

# Whitelist your own IPs
ignoreip = 127.0.0.1/8 ::1 YOUR.HOME.IP.ADDRESS

Enable SSH Protection

[sshd]
enabled  = true
port     = ssh        # or your custom port e.g. 2222
maxretry = 3
bantime  = 24h
sudo systemctl restart fail2ban

Check Status

# Overall status
sudo fail2ban-client status

# SSH jail status — shows banned IPs
sudo fail2ban-client status sshd

# Watch bans in real time
sudo tail -f /var/log/fail2ban.log

Manually Ban and Unban IPs

# Ban an IP manually
sudo fail2ban-client set sshd banip 1.2.3.4

# Unban an IP
sudo fail2ban-client set sshd unbanip 1.2.3.4

# Check if an IP is banned
sudo fail2ban-client get sshd banip | grep 1.2.3.4

Protect Nginx — HTTP Auth Brute Force

[nginx-http-auth]
enabled  = true
port     = http,https
maxretry = 5
bantime  = 1h

Protect Nginx — Bad Bots and 404 Floods

[nginx-botsearch]
enabled  = true
port     = http,https
maxretry = 2
bantime  = 24h

Custom Jail for Any Log File

sudo nano /etc/fail2ban/jail.local
[my-app]
enabled  = true
logpath  = /var/log/my-app/auth.log
maxretry = 5
bantime  = 1h
filter   = my-app    # points to /etc/fail2ban/filter.d/my-app.conf
sudo nano /etc/fail2ban/filter.d/my-app.conf
[Definition]
failregex = ^.*Failed login from .*$
ignoreregex =

Test a Filter

# Test filter against log file before enabling
sudo fail2ban-regex /var/log/auth.log /etc/fail2ban/filter.d/sshd.conf

Permanent Bans

[DEFAULT]
bantime = -1    # negative value = permanent ban

Permanent bans survive restarts but accumulate over time. Consider using a shorter bantime for most jails and permanent only for known bad actors.
