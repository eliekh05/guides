Tailscale Exit Node — Route All Traffic Through Another Machine

A Tailscale exit node lets you route all your internet traffic through another machine on your Tailnet. Useful for accessing region-locked content, securing traffic on public Wi-Fi, or routing through your home network while travelling.

Requirements

  • Tailscale installed on both machines
  • Both machines logged into the same Tailscale account
  • The exit node machine must have a stable internet connection

Set Up the Exit Node (Server Side)

# Enable IP forwarding (required for routing traffic)
echo 'net.ipv4.ip_forward = 1' | sudo tee -a /etc/sysctl.d/99-tailscale.conf
echo 'net.ipv6.conf.all.forwarding = 1' | sudo tee -a /etc/sysctl.d/99-tailscale.conf
sudo sysctl -p /etc/sysctl.d/99-tailscale.conf

# Advertise this machine as an exit node
sudo tailscale up --advertise-exit-node

Approve the Exit Node in Tailscale Admin

  1. Go to https://login.tailscale.com/admin/machines
  2. Find the machine you just configured
  3. Click the three dots → Edit route settings
  4. Enable Use as exit node
  5. Save

Without this approval step, clients cannot use the exit node even if it is advertised.

Use the Exit Node (Client Side)

# Linux / macOS — route all traffic through the exit node
sudo tailscale up --exit-node=MACHINE-NAME-OR-IP

# Use the machine's Tailscale hostname (easier)
sudo tailscale up --exit-node=my-home-server

# Stop using the exit node
sudo tailscale up --exit-node=

On Windows and macOS, you can also select the exit node from the Tailscale system tray icon → Exit nodes.

Allow LAN Access While Using Exit Node

By default, when you use an exit node, local network access (printers, NAS, local devices) is blocked because all traffic goes through the exit node.

# Allow local network access while using exit node
sudo tailscale up --exit-node=my-home-server --exit-node-allow-lan-access

Exit Node on a VPS

If you want a fixed IP in a specific country, install Tailscale on a VPS and use it as an exit node:

# On a cheap VPS (Hetzner, DigitalOcean, Vultr)
curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up --advertise-exit-node --authkey=YOUR-AUTH-KEY

Generate an auth key at https://login.tailscale.com/admin/settings/keys — use a reusable key for servers.

Check Traffic Is Routing Correctly

# Check your public IP — should show the exit node's IP
curl ifconfig.me

# Check Tailscale status
tailscale status
tailscale ping MACHINE-NAME

Mullvad Exit Nodes

Tailscale has a partnership with Mullvad VPN. If you have a Mullvad subscription, you can use Mullvad's servers as exit nodes without running your own:

# List available Mullvad exit nodes
tailscale exit-node list

# Use a Mullvad exit node
sudo tailscale up --exit-node=mullvad.exitnode.country-city

Enable at https://login.tailscale.com/admin/settings/general → Mullvad exit nodes.
