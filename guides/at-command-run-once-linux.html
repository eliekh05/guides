at — Run a Command Once at a Specific Time

The at command schedules a one-time task to run at a specific time. Unlike cron which repeats, at runs a command once and removes the job. Perfect for "run this in 2 hours" or "restart this service at midnight".

Install

sudo apt install at      # Ubuntu/Debian
sudo dnf install at      # Fedora/RHEL
sudo pacman -S at        # Arch

# Enable and start the atd daemon
sudo systemctl enable --now atd

Basic Usage

# Run a command in 2 hours
echo "systemctl restart nginx" | at now + 2 hours

# Run at a specific time today
echo "/usr/local/bin/backup.sh" | at 23:00

# Run at a specific date and time
echo "/usr/local/bin/report.sh" | at 9:00 AM July 25

# Run tomorrow at 8am
echo "apt update && apt upgrade -y" | at 8am tomorrow

Interactive Mode

at now + 1 hour

Type your commands, press Enter after each, then press Ctrl+D to finish. The job is queued.

at 3:00 PM
at> /home/user/scripts/cleanup.sh
at> logger "cleanup ran"
at> 
job 5 at Thu Aug 15 15:00:00 2026

Time Formats

at now + 5 minutes
at now + 2 hours
at now + 3 days
at now + 1 week
at midnight
at noon
at teatime          # 4:00 PM
at 14:30
at 2:30 PM
at 2:30 PM tomorrow
at 2:30 PM Aug 20
at 2:30 PM 08/20/2026

List Queued Jobs

atq
# or
at -l

Output shows job number, execution time, queue, and owner:

5   Thu Aug 15 15:00:00 2026 a youruser
6   Fri Aug 16 09:00:00 2026 a youruser

View Job Contents

at -c 5    # show the full job script for job number 5

Remove a Queued Job

atrm 5     # remove job 5
# or
at -r 5

Run Multiple Commands

# Using a heredoc
at now + 1 hour << 'EOF'
cd /var/www/html
git pull
systemctl restart php-fpm
EOF

Run a Script File

at -f /usr/local/bin/myscript.sh now + 2 hours

Environment Variables

at does not inherit your full shell environment — only a minimal environment is set. Always use full paths in at jobs:

# Wrong — might not find the command
echo "backup.sh" | at midnight

# Correct — full path
echo "/usr/local/bin/backup.sh" | at midnight

# Or source environment first
echo "source /etc/profile && backup.sh" | at midnight

Batch Processing with batch

The batch command is like at but runs the job when system load drops below 1.5 (configurable). Useful for resource-intensive jobs you want to run "when the machine is not busy":

echo "/usr/local/bin/heavy-conversion.sh" | batch
