ncdu — Find What Is Using Your Disk Space

ncdu (NCurses Disk Usage) is an interactive terminal tool for finding what is eating your disk space. Far faster and more useful than du for navigating large directory trees.

Install

sudo apt install ncdu       # Ubuntu/Debian
sudo dnf install ncdu       # Fedora/RHEL
sudo pacman -S ncdu         # Arch
brew install ncdu            # macOS

Basic Usage

# Scan current directory
ncdu

# Scan a specific path
ncdu /var

# Scan the whole system (exclude special filesystems)
sudo ncdu /

# Scan but exclude a path
ncdu / --exclude /proc --exclude /sys --exclude /dev

Navigation

KeyAction
↑ ↓Move up/down the list
Enter / →Enter directory
← / q in dirGo back to parent
dDelete selected file or directory
nSort by name
sSort by size (default)
CSort by item count
gToggle graph/percentage display
eToggle display of hidden files
iShow file info
rRecalculate/refresh
qQuit

Common Places to Check

sudo ncdu /var          # logs, databases, package cache
sudo ncdu /home         # user files
sudo ncdu /tmp          # temp files
sudo ncdu /opt          # installed software
sudo ncdu /usr          # system software

Export Results for Later

# Export scan to file (scan now, browse later without rescanning)
sudo ncdu / -o /tmp/scan.json

# Load the saved scan
ncdu -f /tmp/scan.json

Useful for scanning a remote server and browsing the results locally.

Scan a Remote Server

# Scan remote server and browse locally
ssh user@server 'ncdu -1xo- /' | ncdu -f-

Common Disk Space Culprits

  • /var/log — log files that were never rotated
  • /var/cache/apt or /var/cache/dnf — package manager cache
  • /var/lib/docker — Docker images, stopped containers, build cache
  • ~/.local/share/Trash — items in trash not emptied
  • /tmp — temp files from crashed processes
  • ~/Downloads — forgotten large files
  • Old kernel images in /boot

Quick Cleanup After Finding Culprits

# Clean apt cache
sudo apt clean

# Clean dnf cache
sudo dnf clean all

# Clean Docker
docker system prune -af

# Remove old kernels (Ubuntu)
sudo apt autoremove --purge

# Clear journal logs older than 7 days
sudo journalctl --vacuum-time=7d
