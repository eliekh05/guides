Recover Deleted Files on Linux

Linux has no recycle bin for files deleted from the terminal with rm. Recovery depends on how quickly you act and which filesystem you are using.

Stop Writing to the Disk Immediately

Every second you continue using the system, new data may overwrite the deleted file's blocks. If the file is important:

  1. Stop whatever is writing to the disk
  2. If it is on an external drive, unmount it immediately
  3. If it is the system drive, consider booting from a live USB instead

Check if the File Is Still Open

If a process has the file open, you can recover it even after deletion — Linux only removes the directory entry, not the data, while a process holds it open.

# Find deleted files still held open by processes
lsof | grep deleted

# Recover a file held open by process PID with file descriptor FD
cp /proc/PID/fd/FD /path/to/recovered-file

ext4 — Use extundelete

sudo apt install extundelete     # Debian/Ubuntu
sudo dnf install extundelete     # Fedora

# Unmount the partition first (use a live USB if it is the root partition)
sudo umount /dev/sda2

# Recover all recently deleted files
sudo extundelete /dev/sda2 --restore-all

# Recover a specific file
sudo extundelete /dev/sda2 --restore-file path/to/file.txt

Recovered files appear in RECOVERED_FILES/ in your current directory.

Any Filesystem — Use testdisk and photorec

sudo apt install testdisk    # includes photorec
sudo dnf install testdisk

# For file recovery (photorec recovers by file type, not filename)
sudo photorec /dev/sda2

PhotoRec works on ext4, Btrfs, XFS, NTFS, FAT32. It recovers files by scanning for known file headers — it finds the data but filenames are lost. Good for photos, documents, videos.

# testdisk can sometimes recover with original filenames on ext2/ext3
sudo testdisk /dev/sda2

Btrfs — Use Snapshots

If you have Snapper or automatic snapshots enabled, the deleted file is almost certainly in a snapshot:

# List snapshots
sudo snapper list

# Browse a snapshot
sudo ls /.snapshots/5/snapshot/home/youruser/

# Copy the file back
sudo cp /.snapshots/5/snapshot/home/youruser/deleted-file.txt ~/

Check Backup Locations First

Before running recovery tools, check:

  • ~/.local/share/Trash/ — files deleted via file manager go here
  • Time Machine / Timeshift snapshots
  • Git history if the file was in a repo
  • Cloud sync (Dropbox, Nextcloud) — often keeps deleted file history

Prevent This in the Future

# Alias rm to move to trash instead of permanent delete
# Add to ~/.bashrc or ~/.zshrc:
alias rm='mv --target-directory=$HOME/.local/share/Trash/'

# Or install trash-cli for proper trash support
sudo apt install trash-cli
alias rm='trash-put'

# Then use:
trash-put file.txt       # delete
trash-list               # list trash
trash-restore            # restore
trash-empty              # empty trash
