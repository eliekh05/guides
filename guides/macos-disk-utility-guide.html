macOS Disk Utility — Complete Guide

Disk Utility handles formatting drives, creating partitions, repairing disks, making disk images, and erasing data. It's one of the most useful built-in tools on macOS.

Open Disk Utility

  • Applications → Utilities → Disk Utility
  • Spotlight: Cmd+Space → "Disk Utility"
  • From Recovery Mode: Utilities menu → Disk Utility

Show All Devices

By default Disk Utility hides some drives. Go to View → Show All Devices to see the full picture — physical disks and their partitions.

Erase (Format) a Drive

  1. Select the drive in the sidebar (the top-level disk, not a partition)
  2. Click Erase
  3. Choose a name and format
  4. Click Erase
FormatUse for
APFSAny Mac drive (macOS 10.13+). Best choice for SSDs
Mac OS Extended (HFS+)Hard drives, or drives that need to work with older Macs
ExFATDrives shared between Mac and Windows — no size limits
MS-DOS (FAT32)USB drives for older devices — 4GB file size limit

First Aid — Repair a Disk

First Aid checks the filesystem for errors and repairs what it can.

  1. Select the disk or partition in the sidebar
  2. Click First Aid → Run

If First Aid fails on your startup disk, boot into Recovery Mode (hold Cmd+R on Intel, hold Power button on Apple Silicon) and run First Aid from there instead.

Partition a Drive

  1. Select the top-level disk
  2. Click Partition
  3. Click + to add a partition
  4. Set the size and format for each partition
  5. Click Apply

You can't partition the startup drive while macOS is running — do it from Recovery Mode.

Create a Disk Image

Disk images are .dmg files — containers that can be mounted as virtual drives.

File → New Image → Blank Image
  • Size: how large the image can grow
  • Encryption: 128-bit or 256-bit AES — good for sensitive backups
  • Image Format: sparse bundle grows as you add files; read/write lets you add files later

Create a Disk Image from a Folder

File → New Image → Image from Folder

Useful for making a compressed, portable backup of a folder. Choose "compressed" format to shrink it.

Restore (Clone) a Drive

  1. Select the destination drive
  2. Click Restore
  3. Choose the source (a disk, partition, or .dmg file)
  4. Click Restore

This wipes the destination and makes it an exact copy of the source.

Securely Erase Free Space

On older spinning hard drives, deleted files can be recovered. Erase Free Space overwrites deleted data:

Select a volume → Erase → Security Options

Not useful on SSDs — TRIM handles this automatically and overwriting doesn't work the same way.

Disk Utility from Terminal

# List all disks
diskutil list

# Get info on a disk
diskutil info /dev/disk2

# Erase a drive (replaces Disk Utility GUI)
diskutil eraseDisk APFS "MyDrive" /dev/disk2

# Repair
diskutil repairDisk /dev/disk2
diskutil repairVolume /dev/disk2s1

# Unmount
diskutil unmount /dev/disk2s1
diskutil eject /dev/disk2
