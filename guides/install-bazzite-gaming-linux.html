Install Bazzite — Gaming Linux

Bazzite is an immutable Linux distribution built for gaming. It ships with Steam, Lutris, Heroic Games Launcher, and all gaming drivers pre-configured. Based on Fedora Atomic, it uses OCI image updates — the base OS updates atomically and rolls back automatically if something breaks.

Which Bazzite Image to Download

  • bazzite — GNOME desktop, AMD/Intel GPU, standard PC
  • bazzite-nvidia — GNOME desktop, Nvidia GPU
  • bazzite-deck — Steam Deck-like gaming mode (Gamescope session), AMD/Intel
  • bazzite-deck-nvidia — Gaming mode, Nvidia GPU
  • bazzite-kde — KDE Plasma desktop instead of GNOME

Download from https://bazzite.gg. For a desktop gaming PC with AMD GPU, use bazzite. For Nvidia, use bazzite-nvidia.

Flash and Install

Flash the ISO to USB with Ventoy or balenaEtcher. Boot from USB. Bazzite uses the Anaconda installer — same as Fedora.

Partitioning: Use automatic unless dual booting. Bazzite uses Btrfs by default with automatic snapshot support.

User: Create your account and make it an administrator.

Install takes 5–15 minutes.

First Boot

Bazzite's first-boot wizard (ujust setup-bazzite) walks you through:

  • Installing additional drivers
  • Setting up gaming platforms (Steam, Lutris, Heroic)
  • Installing additional software
  • Configuring game controller support

Installing Software

The base system is immutable — you do not install packages the traditional way. Instead:

# Flatpak — primary way to install apps
flatpak install flathub com.discordapp.Discord
flatpak install flathub org.videolan.VLC

# Layered packages (installed on top of base image, survives updates)
rpm-ostree install htop neovim

# Distrobox — run any distro in a container with full access
distrobox create --name ubuntu --image ubuntu:24.04
distrobox enter ubuntu

Gaming Mode (Gamescope Session)

On bazzite-deck images, you can switch between Desktop Mode and Gaming Mode from the login screen. Gaming Mode launches Gamescope + Steam in a console-like full-screen interface — identical to Steam Deck.

Proton and Wine

Steam with Proton is pre-installed. Enable Proton for a Windows game:

  1. Steam → right-click game → Properties → Compatibility
  2. Check "Force the use of a specific Steam Play compatibility tool"
  3. Select Proton version (latest stable or Proton-GE recommended)

Install Proton-GE (community Proton with extra patches):

ujust install-proton-ge

Update Bazzite

# Check for updates
rpm-ostree upgrade

# Or use the system updater in GNOME Software / Discover

Updates are atomic — if an update breaks something, roll back with:

rpm-ostree rollback

Useful Bazzite Commands

ujust          # list all available Bazzite-specific commands
ujust update   # update everything (OS + Flatpaks)
ujust fix-reset-steam   # reset Steam if it breaks
ujust install-resolve   # install Davinci Resolve
rpm-ostree status      # show current and previous OS image
