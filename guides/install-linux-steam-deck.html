Install Linux on Steam Deck

Steam Deck runs SteamOS 3 (based on Arch Linux) by default. You can also install a different Linux distribution alongside SteamOS using a second storage device or by replacing SteamOS entirely. This guide covers both approaches.

Option 1 — Use the Desktop Mode (No Install Needed)

SteamOS already has a full KDE Plasma desktop. Switch to it:

Hold Power button → Switch to Desktop

From Desktop Mode you have access to a full Linux terminal, Flatpak apps, Discover software center, and most Linux tools. For most users this is sufficient.

Option 2 — Install Flatpaks and Apps on SteamOS

SteamOS's root filesystem is read-only, but you can install apps via Flatpak (persists across updates) and some packages via the unofficial package manager:

# In Desktop Mode, open Konsole (terminal)

# Install Flatpak apps
flatpak install flathub org.videolan.VLC
flatpak install flathub com.visualstudio.code
flatpak install flathub org.gimp.GIMP

# Make root writable (temporary, resets on update)
sudo steamos-readonly disable

# Install packages (resets on SteamOS update)
sudo pacman -Sy package-name

# Re-enable read-only
sudo steamos-readonly enable

Option 3 — Install a Different Distro on a MicroSD Card

Install a Linux distro to a microSD card and dual boot alongside SteamOS.

  1. Download Bazzite (recommended — Steam Deck support built in) or any Linux ISO
  2. Flash to a microSD card with balenaEtcher
  3. Insert the microSD into the Steam Deck
  4. Hold Volume Down + Power to enter boot menu
  5. Select the microSD
  6. Install to the microSD card — do not touch the internal NVMe

To switch between SteamOS and your Linux install: hold Volume Down + Power at boot → select boot device.

Option 4 — Replace SteamOS with Another Distro

This replaces SteamOS. You will lose Gaming Mode and Valve's automatic updates. Bazzite with the deck image is the best replacement — it replicates Gaming Mode on non-SteamOS installs.

  1. Download Bazzite deck image from https://bazzite.gg
  2. Flash to a USB-C flash drive
  3. Connect USB-C hub with the flash drive
  4. Hold Volume Down + Power → select USB device
  5. Install to the internal NVMe — this erases SteamOS

Re-install SteamOS (If Needed)

Valve provides an official SteamOS recovery image:

  1. Download from https://store.steampowered.com/steamos/download/?ver=steamdeck
  2. Flash to a USB-C drive with balenaEtcher
  3. Boot from it and select "Reimage Steam Deck"

Useful Steam Deck Terminal Commands

# Set a password for the deck user (required for sudo)
passwd

# Check SteamOS version
cat /etc/os-release

# List installed Flatpaks
flatpak list

# Update Flatpaks
flatpak update

# Update SteamOS (from Desktop Mode)
sudo steamos-update
