firewalld — Firewall Management on Fedora and RHEL

firewalld is the default firewall manager on Fedora, RHEL, CentOS, Rocky Linux, and AlmaLinux. It uses zones to group rules by trust level — a different approach to UFW, but more flexible once you understand it.

Concepts — Zones

firewalld assigns every network interface to a zone. Each zone has its own set of allowed services and ports. The key zones:

ZoneTrust levelDefault behaviour
dropNoneDrops all incoming, no reply
blockNoneRejects all incoming with ICMP message
publicLowDefault. Only selected services allowed
externalLowFor masquerading/NAT scenarios
homeMediumMore trusted, allows more services
internalMediumFor internal network interfaces
trustedFullAllows everything

Check Status

# Is firewalld running?
sudo systemctl status firewalld

# What zone is each interface in?
sudo firewall-cmd --get-active-zones

# Full config of the default zone
sudo firewall-cmd --list-all

# Config of a specific zone
sudo firewall-cmd --zone=public --list-all

Allow Services

# Allow a named service (firewalld knows common ones)
sudo firewall-cmd --permanent --add-service=ssh
sudo firewall-cmd --permanent --add-service=http
sudo firewall-cmd --permanent --add-service=https

# List available service names
sudo firewall-cmd --get-services

# Allow a specific port
sudo firewall-cmd --permanent --add-port=3000/tcp
sudo firewall-cmd --permanent --add-port=51820/udp

# Allow a port range
sudo firewall-cmd --permanent --add-port=6000-6100/tcp

# Apply changes (required after --permanent changes)
sudo firewall-cmd --reload

Remove Rules

sudo firewall-cmd --permanent --remove-service=http
sudo firewall-cmd --permanent --remove-port=3000/tcp
sudo firewall-cmd --reload

Runtime vs Permanent

firewalld has two layers — runtime (active now, lost on reload) and permanent (saved, applied on reload). Always use --permanent for changes you want to keep, then run --reload.

# Temporary test rule (runtime only)
sudo firewall-cmd --add-port=8080/tcp

# Make it permanent
sudo firewall-cmd --runtime-to-permanent

# Or add it permanent from the start and reload
sudo firewall-cmd --permanent --add-port=8080/tcp
sudo firewall-cmd --reload

Rich Rules — More Control

# Allow SSH only from a specific IP
sudo firewall-cmd --permanent --add-rich-rule='
  rule family="ipv4"
  source address="203.0.113.10"
  service name="ssh"
  accept'

# Block a specific IP
sudo firewall-cmd --permanent --add-rich-rule='
  rule family="ipv4"
  source address="198.51.100.0/24"
  reject'

# Rate limit — allow max 3 SSH connections per minute
sudo firewall-cmd --permanent --add-rich-rule='
  rule service name="ssh"
  accept
  limit value="3/m"'

sudo firewall-cmd --reload

Port Forwarding

# Forward port 8080 to 80 on the same machine
sudo firewall-cmd --permanent --add-forward-port=port=8080:proto=tcp:toport=80

# Forward to another machine
sudo firewall-cmd --permanent --add-forward-port=port=8080:proto=tcp:toport=80:toaddr=192.168.1.50

sudo firewall-cmd --reload

Change Zone for an Interface

# Move eth0 to the home zone
sudo firewall-cmd --permanent --zone=home --change-interface=eth0
sudo firewall-cmd --reload

# Verify
sudo firewall-cmd --get-active-zones

Emergency Block Everything

# Panic mode — drops all incoming and outgoing immediately
sudo firewall-cmd --panic-on

# Disable panic mode
sudo firewall-cmd --panic-off

# Check if panic is on
sudo firewall-cmd --query-panic

Logging Dropped Packets

sudo firewall-cmd --set-log-denied=all
# Options: off, unicast, broadcast, multicast, all

# View in journal
sudo journalctl -k | grep "IN= OUT="

Full Lockdown Example — Public Web Server

sudo firewall-cmd --permanent --zone=public --add-service=ssh
sudo firewall-cmd --permanent --zone=public --add-service=http
sudo firewall-cmd --permanent --zone=public --add-service=https
sudo firewall-cmd --permanent --zone=public --add-rich-rule='rule service name="ssh" accept limit value="3/m"'
sudo firewall-cmd --set-default-zone=public
sudo firewall-cmd --reload
sudo firewall-cmd --list-all
