Coolify — Self-Hosted Heroku Alternative

Coolify is an open-source, self-hosted platform that deploys apps, databases, and services from Git repositories or Docker images. It replaces Heroku, Railway, and Render — push code and Coolify builds and deploys it automatically, on your own server.

Requirements

  • A Linux server (Ubuntu 22.04+ or Debian 12+)
  • Minimum 2 CPU cores, 2 GB RAM (4 GB recommended)
  • A domain name (optional but recommended for HTTPS)

Install Coolify

curl -fsSL https://cdn.coollabs.io/coolify/install.sh | bash

The script installs Docker, Coolify, and all dependencies. Takes 2–5 minutes. Access the dashboard at http://YOUR_SERVER_IP:8000.

Initial Setup

  1. Create your admin account
  2. Set your server URL (use your domain if you have one)
  3. Coolify auto-detects the local Docker daemon — click Validate & Start Proxy

Deploy a Git Repository

  1. Projects → New Project → New Resource
  2. Select Public Repository or connect GitHub/GitLab/Gitea
  3. Enter the repository URL
  4. Coolify detects the language/framework and sets up a build pack automatically (Node.js, Python, PHP, Ruby, Go, Static, Docker, etc.)
  5. Set environment variables if needed
  6. Click Deploy

Deploy a Docker Image

  1. New Resource → Docker Image
  2. Enter image name (e.g. nginx:latest)
  3. Set ports, volumes, environment variables
  4. Deploy

Databases

Coolify provisions managed database instances with one click:

  • PostgreSQL, MySQL, MariaDB, MongoDB, Redis, Dragonfly, KeyDB, Clickhouse

New Resource → Database → select type → Deploy. Coolify handles backups, connection strings, and restores.

Automatic HTTPS

Coolify manages Let's Encrypt certificates automatically via Traefik. Set a domain on any service → Coolify issues and renews the certificate, configures routing.

Git Push to Deploy

Connect your GitHub or GitLab account. On any resource: Settings → Source → enable Automatic Deployment. Coolify registers a webhook — every push to your main branch triggers a new build and deployment.

Multiple Servers

Coolify can manage remote servers — add a server via SSH key and deploy to it from the same dashboard. Useful for separating production from staging.

Update Coolify

curl -fsSL https://cdn.coollabs.io/coolify/install.sh | bash

Re-running the install script updates Coolify in place.
