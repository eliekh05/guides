Fix OneDrive Issues on Windows

OneDrive causes several common problems — taking over the Desktop and Documents folders, filling up disk space, syncing endlessly, or showing errors on files.

Stop OneDrive From Moving Your Desktop and Documents

When OneDrive's folder backup is enabled, it moves Desktop, Documents, and Pictures into the OneDrive folder. Files appear in two places and sync takes up space.

To stop this and move folders back:

  1. Right-click the OneDrive icon in the system tray → Settings
  2. Sync and backup tab → Manage backup
  3. Turn off each folder (Desktop, Documents, Pictures)
  4. Click Stop backup when prompted
  5. Move the files back manually if they were relocated

Stop OneDrive From Starting with Windows

# PowerShell
Get-ItemProperty "HKCU:\Software\Microsoft\Windows\CurrentVersion\Run" | Select OneDrive

# Remove autostart
Remove-ItemProperty "HKCU:\Software\Microsoft\Windows\CurrentVersion\Run" -Name "OneDrive" -ErrorAction SilentlyContinue

Or: Task Manager → Startup apps → Microsoft OneDrive → Disable

Fix Sync Errors

Right-click the OneDrive icon → View sync problems. Common errors:

  • File name too long — Windows has a 260-character path limit. Shorten folder names or enable long paths: reg add "HKLM\SYSTEM\CurrentControlSet\Control\FileSystem" /v LongPathsEnabled /t REG_DWORD /d 1 /f
  • Invalid characters — OneDrive does not support : * ? " < > | # in filenames. Rename the file.
  • File in use — close the application using the file and wait for sync
  • Quota exceeded — you have run out of OneDrive storage

Reset OneDrive

# Stop OneDrive
taskkill /f /im OneDrive.exe

# Reset (clears sync state, does not delete files)
%localappdata%\Microsoft\OneDrive\onedrive.exe /reset

# If the above path does not work:
C:\Program Files\Microsoft OneDrive\onedrive.exe /reset

# Wait 2 minutes, then relaunch
%localappdata%\Microsoft\OneDrive\onedrive.exe

Free Up Local Disk Space (Files On-Demand)

OneDrive's Files On-Demand feature stores files in the cloud and downloads them when opened. Enable it to save local disk space:

  1. Right-click OneDrive tray icon → Settings
  2. Advanced settings → Files On-Demand → Save space and download files as you use them

Or via PowerShell to free up all cloud-backed files:

attrib +U -P /S "C:\Users\YourName\OneDrive\*"

Uninstall OneDrive Completely

# Stop and uninstall
taskkill /f /im OneDrive.exe
winget uninstall Microsoft.OneDrive

# Remove leftover files
Remove-Item "$env:USERPROFILE\OneDrive" -Recurse -ErrorAction SilentlyContinue
Remove-Item "$env:LOCALAPPDATA\Microsoft\OneDrive" -Recurse -ErrorAction SilentlyContinue
Remove-Item "$env:PROGRAMDATA\Microsoft OneDrive" -Recurse -ErrorAction SilentlyContinue

# Remove from registry
reg delete "HKCU\Software\Microsoft\Windows\CurrentVersion\Run" /v OneDrive /f

Prevent OneDrive From Reinstalling

reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows\OneDrive" /v DisableFileSyncNGSC /t REG_DWORD /d 1 /f

Windows updates occasionally reinstall OneDrive. This registry key prevents it.
