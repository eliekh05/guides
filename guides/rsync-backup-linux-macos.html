rsync — Efficient Backups and File Sync

rsync copies only what has changed — making it far faster than cp for backups and syncing large directories. It works locally and over SSH.

Basic Syntax

rsync [options] source destination

Trailing slash on source matters:

# Copy the folder itself
rsync -av /home/user/docs /backup/

# Copy the contents of the folder (trailing slash)
rsync -av /home/user/docs/ /backup/docs/

Essential Options

OptionMeaning
-aArchive mode — preserves permissions, timestamps, symlinks, owner
-vVerbose — show files being transferred
-zCompress during transfer (useful over slow connections)
-PShow progress + keep partial files on interrupt
-nDry run — show what would be transferred without doing it
--deleteDelete files at destination that no longer exist at source
--excludeExclude files matching a pattern
-hHuman readable sizes

Common Use Cases

# Local backup of home directory
rsync -avh --delete /home/user/ /backup/home/

# Dry run first — always do this before --delete
rsync -avhn --delete /home/user/ /backup/home/

# Sync to external drive
rsync -avhP /home/user/Documents/ /media/backup-drive/Documents/

# Exclude directories
rsync -avh \
  --exclude='.cache' \
  --exclude='node_modules' \
  --exclude='*.tmp' \
  /home/user/ /backup/home/

Remote Sync Over SSH

# Local to remote
rsync -avhz /home/user/docs/ user@server:/backup/docs/

# Remote to local
rsync -avhz user@server:/var/www/html/ /local/backup/

# Specify SSH port
rsync -avhz -e "ssh -p 2222" /home/user/ user@server:/backup/

# Use SSH key
rsync -avhz -e "ssh -i ~/.ssh/id_ed25519" /home/user/ user@server:/backup/

Automated Daily Backup Script

#!/bin/bash
# /usr/local/bin/backup.sh

SOURCE="/home/user/"
DEST="/backup/home/"
LOG="/var/log/rsync-backup.log"
DATE=$(date '+%Y-%m-%d %H:%M:%S')

echo "[$DATE] Starting backup" >> "$LOG"

rsync -avh --delete \
  --exclude='.cache' \
  --exclude='node_modules' \
  --exclude='.local/share/Trash' \
  --log-file="$LOG" \
  "$SOURCE" "$DEST"

echo "[$DATE] Backup complete" >> "$LOG"
chmod +x /usr/local/bin/backup.sh

# Schedule with cron — daily at 2 AM
crontab -e
0 2 * * * /usr/local/bin/backup.sh

Incremental Backups with Hardlinks

Keep multiple daily snapshots without using full disk space per snapshot — unchanged files are hardlinked to the previous backup:

#!/bin/bash
DATE=$(date +%Y-%m-%d)
DEST="/backup/snapshots"
LATEST="$DEST/latest"

rsync -avh --delete \
  --link-dest="$LATEST" \
  /home/user/ \
  "$DEST/$DATE/"

# Update the 'latest' symlink
rm -f "$LATEST"
ln -s "$DEST/$DATE" "$LATEST"

Each snapshot directory looks complete but shares unchanged files with previous snapshots via hardlinks — uses only the space of actual changes.

Bandwidth Limiting

# Limit to 1MB/s (useful on metered connections)
rsync -avhz --bwlimit=1000 /source/ user@server:/dest/

Check What Would Change (Itemize)

# Show exactly what would be transferred and why
rsync -avhn --itemize-changes /source/ /dest/

# Output format: YXcstpoguax filename
# Y = update type (< send, > receive, c create, d delete)
# X = file type (f file, d dir, L symlink)
# cstpoguax = what changed (checksum, size, time, permissions, owner...)
