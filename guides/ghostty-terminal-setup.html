Ghostty Terminal Setup

Ghostty is a fast, native terminal emulator built in Zig. It has GPU rendering, splits, tabs, and a built-in config system. It became the most talked-about terminal in 2025 after its public release in December 2024 and is now among the most popular terminals on macOS and Linux.

Install

brew install --cask ghostty    # macOS

On Linux, build from source or use the official package:

# Arch Linux (AUR)
yay -S ghostty-bin

# Flatpak
flatpak install flathub com.mitchellh.ghostty

Config File Location

# macOS
~/.config/ghostty/config

# Linux
~/.config/ghostty/config

Create it if it does not exist:

mkdir -p ~/.config/ghostty
nano ~/.config/ghostty/config

Essential Config Settings

# Font
font-family = JetBrains Mono
font-size = 13

# Theme (built-in themes: ghostty -e --list-themes)
theme = dark:Catppuccin Mocha,light:Catppuccin Latte

# Appearance
background-opacity = 0.95
window-decoration = true

# Performance
cursor-style = block
cursor-style-blink = true

# Shell integration (auto-detects your shell)
shell-integration = true

# macOS specific
macos-option-as-alt = true   # make Option work as Meta for readline shortcuts
window-padding-x = 8
window-padding-y = 8

Keyboard Shortcuts

ShortcutAction
Cmd+TNew tab
Cmd+DNew split (vertical)
Cmd+Shift+DNew split (horizontal)
Cmd+Option+ArrowNavigate between splits
Cmd+WClose tab or split
Cmd+[1-9]Switch to tab by number
Cmd+Shift+EnterZoom split to full window
Cmd+,Open config in editor

List All Built-in Themes

ghostty +list-themes

Shell Integration

Ghostty's shell integration adds:

  • Click to jump between command outputs
  • Semantic prompt tracking
  • Working directory tracking across splits
  • Marks on prompt lines in the scrollback

It activates automatically when shell-integration = true and you are using bash, zsh, fish, or elvish.
