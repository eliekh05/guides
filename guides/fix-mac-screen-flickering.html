Fix Screen Flickering on Mac

Screen flickering on a Mac is usually caused by a GPU driver issue, an external display misconfiguration, or a hardware fault starting to develop. Here's how to tell which one and what to do about it.

First — Narrow It Down

  • Does it flicker on the built-in screen, an external display, or both?
  • Does it happen constantly or only when doing something specific (scrolling, playing video, waking from sleep)?
  • Did it start after a macOS update?

External Display Flickering

If it's only the external monitor:

  • Try a different cable — HDMI and DisplayPort cables degrade and cause flickering
  • Try a different port on your Mac or hub
  • Reduce the refresh rate: System Settings → Displays → select the monitor → change refresh rate from 144Hz to 60Hz
  • Turn off "Automatically adjust brightness" if it's toggling constantly

Disable Automatic Graphics Switching

Macs with dual GPUs (integrated + discrete) switch between them automatically. This switching can cause flickering:

System Settings → Battery → uncheck "Automatic graphics switching"

This forces the discrete GPU to stay on — uses more power but stops the switching flicker.

Reset NVRAM

NVRAM holds display settings. Resetting it clears bad display configs:

Intel Mac: Shut down → power on and hold Option+Command+P+R for 20 seconds until the startup chime plays twice.

Apple Silicon: Just restart — NVRAM resets on every boot.

Reset SMC (Intel Only)

The SMC controls GPU power management. Resetting it can fix GPU-related flickering:

Shut down → hold Shift+Control+Option+Power for 7 seconds → release all → power on normally.

Check for macOS Updates

GPU driver bugs are common right after major macOS releases and usually fixed in .1 or .2 updates. System Settings → General → Software Update.

Check GPU Errors in Logs

log show --predicate 'subsystem contains "gpu"' --last 1h | grep -i error

If you see repeated GPU errors this points to either a driver bug (fixed by update) or failing hardware.

Safe Mode Test

Boot into Safe Mode to check if the flickering is caused by a third-party extension or login item:

Intel: Restart and hold Shift until the login screen appears.
Apple Silicon: Shut down → hold Power until "Loading startup options" appears → select disk → hold Shift → click Continue in Safe Mode.

If the flickering stops in Safe Mode, a login item or extension is the cause. Disable them one by one under System Settings → General → Login Items.

Hardware — When It's the Display Itself

If none of the above helps and the flicker is on the built-in screen, it's likely a hardware issue:

  • Loose display cable — common on MacBook hinges after years of opening and closing
  • Failing GPU — usually accompanied by graphical glitches and artifacts
  • Dying backlight — flicker gets worse in cold temperatures

Book a Genius Bar appointment or run Apple Diagnostics: restart and hold D on Intel, or hold D right after powering on Apple Silicon.
