Install Debian Linux

Debian is one of the oldest and most stable Linux distributions. It's the base that Ubuntu is built on, and it's a solid choice for servers where you want software that just works without constant updates breaking things.

Download

Get the latest stable release from debian.org/distrib/. Download the "amd64 netinst" ISO — it's small (around 400MB) and downloads the rest during installation.

If you have no reliable internet during install, get the full DVD image instead.

Create Bootable USB

# Linux/macOS
sudo dd if=debian-12.x.x-amd64-netinst.iso of=/dev/sdX bs=4M status=progress oflag=sync

# Windows — use Rufus (rufus.ie)

Boot and Start Install

  1. Enter BIOS/UEFI (F2, F12, Del, or Esc) and boot from USB
  2. Select "Graphical install" for the guided installer

Installation Steps

  1. Language and locale — pick your language and region
  2. Hostname — name your machine (e.g. myserver)
  3. Domain — leave blank for a home machine
  4. Root password — set a strong one, or leave blank to disable root login and use sudo instead (recommended)
  5. Create user — your regular user account
  6. Partition disks — "Guided — use entire disk" is fine for most installs. LVM is optional but useful for resizing later
  7. Package manager mirror — pick a mirror in your country for faster downloads
  8. Popularity contest — your call, doesn't affect the install
  9. Software selection:
    • Server: uncheck everything except "SSH server" and "standard system utilities"
    • Desktop: check your preferred desktop environment
  10. GRUB bootloader — install to the primary drive
  11. Reboot when complete and remove the USB

First Login and Update

# Log in as your user
# Update everything
sudo apt update && sudo apt upgrade -y

Enable sudo for Your User

If you set a root password during install, your user might not have sudo access by default:

# Switch to root
su -

# Add your user to sudo group
usermod -aG sudo yourusername

# Exit root
exit

# Log out and back in for group change to take effect

Install Essential Packages

sudo apt install -y \
  curl wget git htop ncdu \
  build-essential \
  ufw \
  unzip zip

Configure Firewall

sudo ufw allow OpenSSH
sudo ufw enable
sudo ufw status

Set Static IP (Server)

sudo nano /etc/network/interfaces
auto eth0
iface eth0 inet static
  address 192.168.1.50
  netmask 255.255.255.0
  gateway 192.168.1.1
  dns-nameservers 1.1.1.1 8.8.8.8
sudo systemctl restart networking
