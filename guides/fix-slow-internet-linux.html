Fix Slow Internet on Linux

Slow internet on Linux is usually one of four things — DNS, Wi-Fi driver issues, network settings not optimised, or a specific app throttling. Work through these in order.

Confirm the Problem Is the OS, Not the Connection

# Test download speed from terminal
curl -s https://raw.githubusercontent.com/sivel/speedtest-cli/master/speedtest.py | python3 -

# Or install speedtest-cli
pip install speedtest-cli
speedtest

# Or use fast.com from terminal
curl -s https://raw.githubusercontent.com/sindresorhus/fast-cli/main/fast | node

Compare with a speed test on another device on the same network. If other devices are fast and Linux is slow, it is a Linux configuration issue.

Fix DNS — Most Common Cause of Slow Browsing

# Test DNS resolution speed
time dig google.com @8.8.8.8      # Google DNS
time dig google.com @1.1.1.1      # Cloudflare DNS
time dig google.com               # Current DNS

# Check what DNS server you are using
resolvectl status | grep "DNS Servers"
# or
cat /etc/resolv.conf

Switch to a faster DNS server:

# NetworkManager — change DNS via settings
nmcli con show                    # list connections
nmcli con mod "CONNECTION-NAME" ipv4.dns "1.1.1.1 8.8.8.8"
nmcli con up "CONNECTION-NAME"

# Flush DNS cache
sudo resolvectl flush-caches

Wi-Fi — Check for Driver Issues

# Check Wi-Fi interface and signal strength
iwconfig
iwconfig wlan0 | grep -E "Bit Rate|Signal level|Link Quality"

# Check for driver errors
dmesg | grep -i "wifi\|wlan\|wireless\|80211" | tail -20

# Check what driver is in use
lspci -k | grep -A3 "Network controller"
# or for USB Wi-Fi
lsusb | grep -i wireless

Disable Wi-Fi Power Saving

Power saving puts the Wi-Fi adapter to sleep between packets — causes high latency and slow speeds especially on Intel Wi-Fi cards.

# Check current power management state
iwconfig wlan0 | grep "Power Management"

# Disable power saving
sudo iwconfig wlan0 power off

# Make it permanent
sudo nano /etc/NetworkManager/conf.d/wifi-powersave.conf
[connection]
wifi.powersave = 2
sudo systemctl restart NetworkManager

Enable BBR Congestion Control

BBR is a modern TCP congestion control algorithm that improves throughput on high-latency connections.

# Check current algorithm
sysctl net.ipv4.tcp_congestion_control

# Enable BBR
echo "net.core.default_qdisc=fq" | sudo tee -a /etc/sysctl.conf
echo "net.ipv4.tcp_congestion_control=bbr" | sudo tee -a /etc/sysctl.conf
sudo sysctl -p

# Verify
sysctl net.ipv4.tcp_congestion_control

Increase Network Buffer Sizes

sudo nano /etc/sysctl.conf
net.core.rmem_max=16777216
net.core.wmem_max=16777216
net.ipv4.tcp_rmem=4096 87380 16777216
net.ipv4.tcp_wmem=4096 65536 16777216
sudo sysctl -p

Check for Network Interface Errors

# Check for packet errors and drops
ip -s link show
netstat -s | grep -E "errors|dropped|failed"

# Watch real-time interface stats
watch -n1 'ip -s link show wlan0'

Test with a Different DNS and Compare

# Test latency to various DNS servers
for dns in 1.1.1.1 8.8.8.8 9.9.9.9 208.67.222.222; do
  echo -n "$dns: "; ping -c3 $dns | tail -1
done

Check if VPN Is Throttling

If you are using a VPN, disconnect it and retest. VPNs add overhead and many free VPNs throttle speeds significantly.
