Windows 10 End of Life — What to Do

Windows 10 reached end of life on October 14, 2025. Microsoft no longer provides security updates, bug fixes, or technical support. Continuing to use it is a security risk — vulnerabilities found after that date will never be patched.

Your Options

Option 1 — Upgrade to Windows 11 (Supported Hardware)

If your PC meets Windows 11 requirements (TPM 2.0, Secure Boot, 64-bit CPU from 2017 or later), upgrade is free:

Settings → Windows Update → Check for updates

If Windows Update does not offer it, download the Installation Assistant from microsoft.com/en-us/software-download/windows11.

Option 2 — Install Windows 11 on Unsupported Hardware

See the Install Windows 11 on Unsupported PC guide. The registry bypass works reliably and gives you full Windows 11 — Microsoft has not blocked it as of 2026.

Option 3 — Extended Security Updates (ESU) — Paid

Microsoft offers paid Extended Security Updates for Windows 10 for individuals and businesses. As of 2026, Year 1 ESU costs $30 per device for consumers. This buys you security patches until October 2026. Enroll at microsoft.com/en-us/windows/windows-10-eol-faq.

Option 4 — Switch to Linux

If your hardware is too old for Windows 11 and you do not want to pay for ESU, Linux is a genuine alternative. See the Which Linux Distribution Should You Use guide. Linux Mint runs well on hardware from 2010 onwards.

The main blockers:

  • No TPM 2.0 — most PCs from 2017+ have it, may need enabling in BIOS
  • Secure Boot disabled — enable in BIOS/UEFI settings
  • CPU too old — Intel 7th gen or earlier, AMD Ryzen 1000 series

Enable TPM 2.0 in BIOS

Restart → enter BIOS (usually F2, F10, DEL, or F12 during boot) → look for TPM, PTT (Intel Platform Trust Technology), or fTPM (AMD) under Security or Advanced settings → Enable → Save.

Back Up Before Doing Anything

Whatever path you choose, back up your important files first. Upgrading Windows should preserve your files, but hardware failures, power cuts during upgrade, and unexpected incompatibilities can cause data loss.
