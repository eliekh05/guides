Proxmox — First Steps After Install

Proxmox VE is an open-source hypervisor for running virtual machines and containers. After a fresh install, several important steps make it production-ready and remove the subscription nag.

Access the Web Interface

Open a browser and go to https://YOUR-SERVER-IP:8006. Login as root with the password you set during install. Accept the self-signed certificate warning.

Remove the Subscription Nag

# SSH into your Proxmox server and run:
sed -Ezi.bak "s/(Ext.Msg.show\(\{[\s\S]*?Proxmox VE.*?\}.*?\);)/void(0);/g" \
  /usr/share/javascript/proxmox-widget-toolkit/proxmoxlib.js

# Restart the web service
systemctl restart pveproxy

Or use the community script that handles this automatically:

bash -c "$(wget -qLO - https://github.com/tteck/Proxmox/raw/main/misc/post-pve-install.sh)"

Switch to No-Subscription Repository

The default repository requires a paid subscription. Switch to the free community repo:

# Disable enterprise repo
echo "# deb https://enterprise.proxmox.com/debian/pve bookworm pve-enterprise" > /etc/apt/sources.list.d/pve-enterprise.list

# Add no-subscription repo
echo "deb http://download.proxmox.com/debian/pve bookworm pve-no-subscription" > /etc/apt/sources.list.d/pve-no-subscription.list

# Update
apt update && apt full-upgrade -y

Update Proxmox

apt update && apt dist-upgrade -y
reboot

Upload an ISO

  1. In the web UI: select your node (pve) → local storage → ISO Images
  2. Click Upload to upload from your computer
  3. Or click Download from URL to fetch directly to the server (faster)

Create a Virtual Machine

  1. Click Create VM in the top right
  2. General: set VM ID and name
  3. OS: select the ISO you uploaded
  4. System: keep defaults (OVMF for UEFI, SeaBIOS for legacy)
  5. Disks: set disk size (32 GB minimum for Linux, 64 GB for Windows)
  6. CPU: set core count (2 minimum)
  7. Memory: set RAM (2048 MB minimum for Linux, 4096 for Windows)
  8. Network: keep default (virtio bridge)
  9. Confirm and start the VM

Create an LXC Container

Containers are lighter than VMs — good for services like Nginx, databases, or Home Assistant.

  1. Download a template: node → local → CT Templates → Templates → select and download
  2. Click Create CT
  3. Set hostname, password, template, disk size, CPU, memory
  4. Start the container

Enable IOMMU for GPU Passthrough

# Edit GRUB
nano /etc/default/grub

# Change GRUB_CMDLINE_LINUX_DEFAULT to:
GRUB_CMDLINE_LINUX_DEFAULT="quiet intel_iommu=on iommu=pt"
# (use amd_iommu=on for AMD CPUs)

update-grub

# Add kernel modules
echo -e "vfio\nvfio_iommu_type1\nvfio_pci\nvfio_virqfd" >> /etc/modules

update-initramfs -u -k all
reboot

Useful Proxmox Commands

pvesh get /nodes                          # list nodes
qm list                                   # list VMs
pct list                                  # list containers
qm start 100                              # start VM 100
qm stop 100                               # stop VM 100
qm snapshot 100 snap1                     # snapshot VM 100
pveversion                                # Proxmox version
pvecm status                              # cluster status (if clustered)

Backups

Datacenter → Backup → Add. Set schedule, storage, and which VMs/containers to include. Proxmox creates consistent backups by briefly suspending or using QEMU snapshots.
