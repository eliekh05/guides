sed and awk — Edit and Process Text in the Terminal

sed and awk are text processing tools that can search, replace, filter, and transform text — often without writing a script. They're especially useful for editing files in bulk or extracting data from command output.

sed — Stream Editor

sed reads input line by line and applies transformations. The most common use is find and replace.

# Basic find and replace
sed 's/old/new/' file.txt          # replace first occurrence per line
sed 's/old/new/g' file.txt         # replace all occurrences
sed 's/old/new/gi' file.txt        # case-insensitive, all occurrences

# Edit in place (modify the file directly)
sed -i 's/old/new/g' file.txt

# macOS requires an empty string after -i
sed -i '' 's/old/new/g' file.txt

sed — Print, Delete, and Filter Lines

# Print specific lines
sed -n '5p' file.txt           # line 5 only
sed -n '5,10p' file.txt        # lines 5 to 10

# Delete lines matching a pattern
sed '/pattern/d' file.txt

# Delete blank lines
sed '/^$/d' file.txt

# Delete line 3
sed '3d' file.txt

# Print lines matching a pattern
sed -n '/error/p' file.txt

sed — Useful Real Examples

# Add a line before a match
sed '/pattern/i\new line here' file.txt

# Add a line after a match
sed '/pattern/a\new line here' file.txt

# Remove trailing whitespace
sed 's/[[:space:]]*$//' file.txt

# Replace multiple spaces with one
sed 's/  */ /g' file.txt

# Comment out a line containing a pattern
sed 's/^.*pattern.*/#&/' file.txt

# Remove HTML tags
sed 's/<[^>]*>//g' file.html

awk — Pattern Scanning and Data Extraction

awk works on columns of data. It splits each line into fields (separated by whitespace by default) and lets you work with them.

# Print the second column
awk '{print $2}' file.txt

# Print first and third columns
awk '{print $1, $3}' file.txt

# Print the last column
awk '{print $NF}' file.txt

# Print lines where column 3 is greater than 100
awk '$3 > 100' file.txt

# Print line number alongside content
awk '{print NR, $0}' file.txt

awk — Custom Delimiter

# Use colon as delimiter (e.g. /etc/passwd)
awk -F: '{print $1}' /etc/passwd         # print usernames
awk -F: '{print $1, $7}' /etc/passwd     # username + shell

# Use comma as delimiter (CSV)
awk -F, '{print $2}' data.csv

awk — Pattern Matching

# Print lines matching a pattern
awk '/error/' logfile.txt

# Print lines NOT matching
awk '!/error/' logfile.txt

# Match on a specific field
awk '$3 == "FAILED"' logfile.txt

# Print lines between two patterns
awk '/START/,/END/' file.txt

awk — Calculations

# Sum a column of numbers
awk '{sum += $1} END {print sum}' numbers.txt

# Average
awk '{sum += $1; count++} END {print sum/count}' numbers.txt

# Count lines matching pattern
awk '/error/{count++} END {print count}' logfile.txt

# Print lines longer than 80 characters
awk 'length($0) > 80' file.txt

Combining sed and awk with Pipes

# Extract usernames from passwd and format them
awk -F: '{print $1}' /etc/passwd | sed 's/^/User: /'

# Get disk usage for a specific filesystem
df -h | awk '/\/dev\/sda/ {print $5}'

# Count failed SSH attempts
grep "Failed password" /var/log/auth.log | awk '{print $11}' | sort | uniq -c | sort -rn

# Extract IP addresses from a log
grep -o '[0-9]\{1,3\}\.[0-9]\{1,3\}\.[0-9]\{1,3\}\.[0-9]\{1,3\}' access.log | sort | uniq -c | sort -rn
