Wazuh — Open Source Intrusion Detection and SIEM

Wazuh is a free, open source security platform that combines intrusion detection (HIDS), log analysis, file integrity monitoring, vulnerability detection, and a SIEM dashboard. It's what security teams use to know what's actually happening across their infrastructure.

Architecture

  • Wazuh Manager — the server that collects, analyses, and stores data. Runs on Linux.
  • Wazuh Agent — lightweight daemon on each machine you want to monitor. Sends events to the manager.
  • Wazuh Dashboard — web UI built on OpenSearch. Where you actually see everything.

Install the Wazuh Server (All-in-One)

The quickest way to get started — installs manager, indexer, and dashboard on one machine. Needs at least 4GB RAM, 2 CPUs, 50GB disk.

curl -sO https://packages.wazuh.com/4.9/wazuh-install.sh
curl -sO https://packages.wazuh.com/4.9/config.yml
# Edit config.yml — set the node name and IP
nano config.yml
nodes:
  indexer:
    - name: node-1
      ip: "YOUR_SERVER_IP"
  server:
    - name: wazuh-1
      ip: "YOUR_SERVER_IP"
  dashboard:
    - name: dashboard
      ip: "YOUR_SERVER_IP"
# Generate config and install
bash wazuh-install.sh --generate-config-files
bash wazuh-install.sh --wazuh-indexer node-1
bash wazuh-install.sh --start-cluster
bash wazuh-install.sh --wazuh-server wazuh-1
bash wazuh-install.sh --wazuh-dashboard dashboard

The install script prints the admin password at the end. Access the dashboard at https://YOUR_IP.

Install an Agent (Linux)

# On the machine you want to monitor
curl -so wazuh-agent.deb \
  https://packages.wazuh.com/4.x/apt/pool/main/w/wazuh-agent/wazuh-agent_4.9.0-1_amd64.deb

sudo WAZUH_MANAGER='YOUR_MANAGER_IP' dpkg -i wazuh-agent.deb
sudo systemctl enable --now wazuh-agent

Install an Agent (Windows)

# Run in PowerShell as Administrator
Invoke-WebRequest -Uri https://packages.wazuh.com/4.x/windows/wazuh-agent-4.9.0-1.msi -OutFile wazuh-agent.msi

msiexec.exe /i wazuh-agent.msi /q WAZUH_MANAGER="YOUR_MANAGER_IP"

NET START WazuhSvc

What Wazuh Detects Out of the Box

  • File integrity monitoring — alerts when system files change (/etc/passwd, /etc/shadow, binaries)
  • Log analysis — reads syslog, auth.log, Windows Event Log, nginx, Apache, and hundreds more
  • Rootkit detection — scans for hidden processes, files, and ports
  • Policy monitoring — checks against CIS benchmarks automatically
  • Vulnerability detection — compares installed packages against CVE databases
  • Active response — can automatically block IPs with fail2ban or firewall rules

Useful Commands

# Manager status
sudo systemctl status wazuh-manager

# Agent status (on the agent machine)
sudo systemctl status wazuh-agent

# Check agent connection on manager
sudo /var/ossec/bin/agent_control -l

# Run rootcheck manually
sudo /var/ossec/bin/wazuh-control restart

# View recent alerts
sudo tail -f /var/ossec/logs/alerts/alerts.log
