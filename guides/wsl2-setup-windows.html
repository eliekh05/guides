WSL2 Setup — Linux on Windows

Windows Subsystem for Linux 2 (WSL2) runs a real Linux kernel inside Windows. You get a full Linux terminal, package manager, and development environment — all integrated with Windows files and apps.

Requirements

  • Windows 10 version 2004+ (Build 19041+) or Windows 11
  • 64-bit system with virtualization enabled in BIOS

Install WSL

Open PowerShell as Administrator and run:

wsl --install

This installs WSL2 and Ubuntu by default. Restart when prompted.

After restarting, Ubuntu opens automatically and asks you to create a Linux username and password.

Install a Different Distro

# List available distros
wsl --list --online

# Install a specific one
wsl --install -d Debian
wsl --install -d kali-linux
wsl --install -d openSUSE-42

Basic WSL Commands (PowerShell)

# List installed distros
wsl --list --verbose

# Launch default distro
wsl

# Launch a specific distro
wsl -d Ubuntu

# Shutdown all WSL instances
wsl --shutdown

# Set default distro
wsl --set-default Ubuntu

Access Windows Files from Linux

# Windows C: drive is mounted at /mnt/c
ls /mnt/c/Users/YourName/

# Navigate to your Windows Downloads folder
cd /mnt/c/Users/YourName/Downloads

Access Linux Files from Windows

In File Explorer, navigate to \\wsl$\Ubuntu\ or click the Linux penguin icon in the sidebar. You can drag files in and out normally.

From the Linux terminal, open the current folder in Windows Explorer:

explorer.exe .

Install Development Tools

# Update packages
sudo apt update && sudo apt upgrade -y

# Common dev tools
sudo apt install build-essential git curl wget unzip -y

# Node.js (via nvm — recommended)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
source ~/.bashrc
nvm install --lts

# Python
sudo apt install python3 python3-pip python3-venv -y

# Docker (use Docker Desktop for Windows, not apt)

VS Code Integration

Install the WSL extension in VS Code. Then from your Linux terminal:

code .    # opens VS Code connected to WSL

VS Code runs natively on Windows but the file system and terminal operate inside Linux.

Configure WSL Resources

Create C:\Users\YourName\.wslconfig to limit memory and CPU:

[wsl2]
memory=4GB       # default is 50% of RAM
processors=2     # default is all logical CPUs
swap=2GB
localhostForwarding=true
# Apply changes
wsl --shutdown

Run Linux GUI Apps

WSL2 on Windows 11 (and updated Windows 10) supports GUI apps via WSLg:

# Install a GUI app
sudo apt install gedit -y

# Launch it (opens a native window on Windows)
gedit

Port Forwarding

Ports open in WSL2 are automatically forwarded to Windows localhost. If you start a web server on port 3000 in Linux, open http://localhost:3000 in your Windows browser.

Troubleshooting

# Enable virtualization if WSL install fails
# Go to BIOS/UEFI → enable Intel VT-x or AMD-V

# Reset a distro to factory state
wsl --unregister Ubuntu
wsl --install -d Ubuntu

# Check WSL version
wsl --status

# Update WSL kernel
wsl --update
