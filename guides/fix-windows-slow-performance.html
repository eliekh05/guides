Fix Slow Performance on Windows 11 and 10

A slow Windows machine is almost never a hardware problem — it's usually startup programs, background services, bloat, or a filesystem that needs attention. Most of these fixes take under 10 minutes.

Check What's Actually Using Resources

Ctrl+Shift+Esc → Task Manager → click "More details"

Sort by CPU, then Memory, then Disk. If something is pegging a resource and it's not something you're actively using, that's your culprit.

Disable Startup Programs

This is the single most effective fix for slow startup and general sluggishness:

Task Manager → Startup apps tab

Right-click and disable anything you don't need running at login. Common offenders: Teams, Spotify, Discord, OneDrive, Adobe updaters, printer software, old apps you've forgotten about.

Adjust Power Plan

Control Panel → Power Options → choose "High performance" or "Balanced"
(not "Power saver")

On laptops, Windows sometimes defaults to power-saving mode which throttles the CPU. Plugging in should switch automatically, but manually setting "Balanced" ensures it.

Free Up Disk Space

Windows slows significantly when the drive is over 90% full:

Win+R → cleanmgr → select C: → check all boxes → also click "Clean up system files"

Or use Settings → System → Storage → Cleanup recommendations.

Enable Storage Sense to automatically clean up temp files:

Settings → System → Storage → Storage Sense → turn on

Run Disk Check and System File Repair

# Open Command Prompt as Administrator
sfc /scannow

# If issues found, run DISM first then sfc again
DISM /Online /Cleanup-Image /RestoreHealth
sfc /scannow

Check for Malware

Background malware is a common cause of unexplained slowness:

Windows Security → Virus & threat protection → Quick scan

Or download Malwarebytes (free version) for a second opinion.

Adjust Visual Effects

Win+R → sysdm.cpl → Advanced tab → Performance Settings
→ choose "Adjust for best performance"

This disables animations and visual effects — makes Windows feel noticeably faster on older hardware.

Disable Search Indexing (Older/Slower Machines)

Services → Windows Search → right-click → Properties → Startup type: Disabled

Windows constantly indexes files in the background. On spinning hard drives this causes constant disk activity. Disabling it means Windows Search is slower but the system overall feels snappier.

Update Drivers

Outdated chipset, storage, or GPU drivers can cause slowdowns:

Device Manager → right-click key devices → Update driver

For best results, go to your PC or motherboard manufacturer's website and download drivers directly rather than relying on Windows Update.

Check if It's the Drive

Spinning hard drives (HDDs) are dramatically slower than SSDs. If your system drive is an HDD, upgrading to an SSD is the single biggest performance improvement possible — more impactful than any software fix.

Task Manager → Performance → Disk
# If disk is at 100% constantly, the drive is the bottleneck

Download CrystalDiskInfo to check drive health — a failing drive causes severe slowdowns before it dies completely.

Restart Regularly

Windows accumulates memory leaks and stale processes over time. If you leave your machine running for weeks, a restart often dramatically improves performance without any other changes.
