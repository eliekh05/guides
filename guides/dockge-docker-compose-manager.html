Dockge — Docker Compose Stack Manager

Dockge is a self-hosted Docker Compose manager with a clean web UI. It lets you create, edit, start, stop, and monitor Docker Compose stacks from a browser. Simpler than Portainer for people who only need Compose management.

Install

mkdir -p /opt/stacks /opt/dockge
cd /opt/dockge
curl https://dockge.kuma.pet/compose.yaml --output compose.yaml
docker compose up -d

Open http://YOUR_SERVER_IP:5001 and create your admin account.

What It Does

  • Manage all your Docker Compose stacks from one interface
  • Built-in editor for docker-compose.yml with syntax highlighting
  • Start, stop, restart, pull, and delete stacks with one click
  • Live log viewer per container
  • Terminal into any running container
  • Interactive Compose file editor — add services, environment variables, volumes through a form

Add an Existing Stack

Place your existing docker-compose.yml files in /opt/stacks/ — each stack goes in its own subfolder:

mkdir -p /opt/stacks/nextcloud
# Copy your compose file:
cp ~/nextcloud/docker-compose.yml /opt/stacks/nextcloud/

Dockge auto-detects stacks in /opt/stacks and shows them in the UI.

Create a New Stack from UI

  1. Click + → Compose
  2. Enter stack name
  3. Paste or write your docker-compose.yml
  4. Add environment variables in the ENV tab (saves to .env file)
  5. Click Deploy

Docker Compose Setup

services:
  dockge:
    image: louislam/dockge:1
    restart: unless-stopped
    ports:
      - 5001:5001
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock
      - /opt/dockge/data:/app/data
      - /opt/stacks:/opt/stacks

Dockge vs Portainer

FeatureDockgePortainer
Compose focusYes — built for itPartial
Individual container managementNoYes
UI complexitySimpleComplex
Multi-serverNoYes (agent)
Image managementNoYes
Resource usageVery lightHeavier

Use Dockge if you only run Compose stacks and want a simple interface. Use Portainer if you need full Docker management, image inspection, or multi-server support.

Update Dockge

cd /opt/dockge
docker compose pull
docker compose up -d
