Set Up Pi-hole — Network-Wide Ad Blocking

Pi-hole is a DNS sinkhole that blocks ads and trackers at the network level. Every device on your network gets ad blocking — phones, smart TVs, game consoles — without installing anything on them.

What You Need

  • A Raspberry Pi, old PC, or any Linux machine that stays on 24/7
  • Ubuntu, Debian, or Raspberry Pi OS
  • A static IP for that machine

Set a Static IP First

Pi-hole needs a fixed IP — if it changes, DNS breaks for your whole network.

# Find your current IP and gateway
ip a
ip route | grep default

# Set static IP via netplan (Ubuntu)
sudo nano /etc/netplan/01-netcfg.yaml
network:
  version: 2
  ethernets:
    eth0:
      dhcp4: no
      addresses: [192.168.1.10/24]
      routes:
        - to: default
          via: 192.168.1.1
      nameservers:
        addresses: [1.1.1.1, 8.8.8.8]
sudo netplan apply

Install Pi-hole

curl -sSL https://install.pi-hole.net | bash

The installer walks you through the setup interactively:

  1. Select your network interface (usually eth0 or wlan0)
  2. Choose an upstream DNS provider — Cloudflare (1.1.1.1) or Quad9 are good choices
  3. Keep the default blocklists
  4. Install the web admin interface — yes
  5. Enable logging
  6. Note the admin password shown at the end

Access the Web Interface

http://192.168.1.10/admin    # use your Pi-hole's IP

Log in with the password shown at end of install, or reset it:

pihole -a -p newpassword

Point Your Router at Pi-hole

The most effective setup: change the DNS server in your router so every device on the network uses Pi-hole automatically.

  1. Log into your router (usually 192.168.1.1 or 192.168.0.1)
  2. Find DNS settings — usually under DHCP or WAN settings
  3. Set Primary DNS to your Pi-hole's IP (e.g. 192.168.1.10)
  4. Set Secondary DNS to a fallback like 1.1.1.1 (optional — if empty, outage = no internet)
  5. Save and restart the router

Update Blocklists

# Update gravity (blocklists) manually
pihole -g

# Update Pi-hole itself
pihole -up

Whitelist a Domain That Got Blocked

# From the terminal
pihole -w example.com

# Or from the web interface:
# Whitelist → add domain

Check What's Being Blocked

The web dashboard shows a live query log — every DNS request on your network. You can see which device is querying what, and which domains are being blocked. Useful for finding broken services.

Add More Blocklists

Pi-hole ships with good defaults. You can add more from the web interface under Group Management → Adlists. Popular additions:

  • Steven Black's hosts: https://raw.githubusercontent.com/StevenBlack/hosts/master/hosts
  • OISD: https://abp.oisd.nl/

After adding lists run pihole -g to update gravity.

Pi-hole Behind a VPN

If you run WireGuard or Tailscale, set Pi-hole as the DNS server in your VPN config so you get ad blocking even when away from home.

# In WireGuard client config
[Interface]
DNS = 192.168.1.10    # your Pi-hole IP

Useful Commands

pihole status           # check if Pi-hole is running
pihole -d               # run diagnostics
pihole tail             # live query log in terminal
pihole disable 5m       # temporarily disable for 5 minutes
pihole enable           # re-enable
