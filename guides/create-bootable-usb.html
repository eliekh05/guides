Create a Bootable USB Drive — Every Tool, Every Platform

A bootable USB lets you install an operating system, run a live environment, or recover a broken system. This guide covers every major tool across Windows, macOS, and Linux — including Ventoy, which lets you put multiple ISOs on one drive.

What You Need

  • A USB drive — 8GB minimum, 16GB+ recommended. Everything on it will be erased.
  • The ISO file for the OS you want to install
  • One of the tools below

Ventoy — One USB, Many ISOs (Recommended)

Ventoy is the best option if you use bootable USBs regularly. You install Ventoy once onto the drive, then just copy ISO files onto it like normal files. Boot the USB and pick which ISO to boot from a menu. No re-flashing needed when you download a new ISO.

Download: ventoy.net/en/download.html

Ventoy on Windows

  1. Download and extract the Ventoy zip
  2. Run Ventoy2Disk.exe as Administrator
  3. Select your USB drive from the Device dropdown
  4. Click Install — this erases the drive and sets up Ventoy
  5. Once done, the USB shows up as a normal drive in Explorer
  6. Copy any ISO files directly onto the drive
  7. Boot from the USB — Ventoy shows a menu to pick which ISO to boot

Ventoy on Linux

# Extract the downloaded archive
tar xzf ventoy-*.tar.gz
cd ventoy-*/

# Find your USB drive
lsblk

# Install Ventoy (replace sdX with your drive — this erases it)
sudo ./Ventoy2Disk.sh -i /dev/sdX

# The USB now has a large partition — copy ISOs onto it
sudo mount /dev/sdX1 /mnt
sudo cp ubuntu-24.04.iso /mnt/
sudo umount /mnt

Ventoy on macOS

# Extract the downloaded archive
cd ventoy-*/

# Find your USB drive
diskutil list

# Install Ventoy (replace diskN with your drive)
sudo ./Ventoy2Disk.sh -i /dev/diskN

# Copy ISOs onto the drive once complete

Balena Etcher — Simplest Single-ISO Tool

Etcher is the easiest option for flashing a single ISO. Works identically on Windows, macOS, and Linux. Three clicks: select image, select drive, flash.

Download: etcher.balena.io

  1. Download and install Etcher for your platform
  2. Open Etcher → click Flash from file → select your ISO
  3. Click Select target → choose your USB drive
  4. Click Flash — Etcher verifies the write automatically when done

Etcher protects you from accidentally selecting your system drive by greying out fixed disks.

Rufus — Windows Only, Most Control

Rufus is the most feature-rich Windows tool. It handles Windows 11 TPM bypasses, GPT vs MBR, and lets you customise the install (skip Microsoft account, set username) before flashing.

Download: rufus.ie — portable, no install needed

  1. Open Rufus (run as Administrator for best results)
  2. Select your USB drive under Device
  3. Click SELECT and choose your ISO
  4. Partition scheme: GPT for modern UEFI systems, MBR for old BIOS-only machines
  5. File system: leave as default (Rufus sets this based on the ISO)
  6. Click START

For Windows 11 ISOs, Rufus offers to remove TPM, Secure Boot, and RAM requirements — and to skip the Microsoft account requirement during setup.

dd — Linux and macOS Command Line

dd is built into every Linux and macOS system. It's fast and reliable but has no safety net — double-check your drive letter before running it.

# Find your USB drive (look for the size to identify it)
lsblk                    # Linux
diskutil list            # macOS

# Unmount the drive (don't eject — just unmount)
sudo umount /dev/sdX     # Linux (replace sdX)
diskutil unmountDisk /dev/diskN    # macOS (replace diskN)

# Write the ISO
# Linux
sudo dd if=/path/to/image.iso of=/dev/sdX bs=4M status=progress oflag=sync

# macOS (use rdiskN for faster writes)
sudo dd if=/path/to/image.iso of=/dev/rdiskN bs=4m

The status=progress flag shows transfer speed and progress. Without it dd appears frozen — it isn't, just wait.

GNOME Disks — Linux GUI

If you're on a GNOME desktop (Ubuntu, Fedora, etc.), GNOME Disks is already installed and handles bootable USBs cleanly.

  1. Open Disks from your app launcher
  2. Select your USB drive in the left panel
  3. Click the menu (three dots, top right) → Restore Disk Image
  4. Select your ISO file
  5. Click Start Restoring

Startup Disk Creator — Ubuntu Built-In

Ubuntu ships with Startup Disk Creator for making Ubuntu bootable USBs specifically.

  1. Search for Startup Disk Creator in the app launcher
  2. Select the ISO under "Source disc image"
  3. Select your USB under "Disk to use"
  4. Click Make Startup Disk

Only works well with Ubuntu and Ubuntu-based ISOs. For anything else use dd or Etcher.

If the USB doesn't appear in the boot menu, check that Secure Boot is disabled in UEFI settings for Linux ISOs (Windows 11 needs it enabled).

Troubleshooting

ProblemFix
USB not in boot menuDisable Secure Boot in UEFI, try a different USB port (use USB 2.0 ports for older BIOSes)
Boots then black screenTry adding nomodeset to boot parameters at the GRUB menu
Windows says USB is corruptedRe-flash with Rufus — some tools don't produce Windows-bootable drives correctly
dd appears frozenIt's writing — wait. Use status=progress next time
Ventoy not bootingMake sure ISO is in the root of the Ventoy partition, not in a subfolder
UEFI only boots in legacy modeSwitch partition scheme to GPT in Rufus, or re-flash
