Fix Wi-Fi Issues on Mac

Wi-Fi problems on macOS usually fall into a few categories — slow speeds, dropping connection, not connecting after wake, or not seeing a network at all.

Basic Checks First

  • Restart your router — unplug it for 30 seconds
  • Toggle Wi-Fi off and on from the menu bar
  • Check if other devices on the same network have issues — if they do, it is the router, not your Mac
  • Move closer to the router to rule out signal strength

Forget and Reconnect

  1. System Settings → Wi-Fi → click the network name → Forget This Network
  2. Reconnect and enter the password again

Flush DNS and Renew DHCP

# Flush DNS cache
sudo dscacheutil -flushcache && sudo killall -HUP mDNSResponder

# Renew DHCP lease
sudo ipconfig set en0 DHCP    # en0 is usually Wi-Fi

Delete Wi-Fi Preferences

Corrupted network preferences cause persistent Wi-Fi issues:

sudo rm /Library/Preferences/com.apple.airport.preferences.plist
sudo rm -rf /Library/Preferences/SystemConfiguration/
sudo reboot

macOS recreates these files on reboot. You will need to reconnect to all saved networks.

Fix Wi-Fi Dropping After Sleep

System Settings → Battery → Options → disable Enable Power Nap and Wake for network access. Power Nap wakes the Mac periodically which can disrupt Wi-Fi reconnection.

# Also try resetting the Wi-Fi interface
sudo ifconfig en0 down
sudo ifconfig en0 up

Check for Channel Interference

If your Mac shows full Wi-Fi bars but speeds are slow, neighboring Wi-Fi networks may be using the same channel.

# Open Wireless Diagnostics
/System/Library/CoreServices/Wi-Fi\ Diagnostics.app

# Or hold Option and click the Wi-Fi icon for quick stats

In Wireless Diagnostics: Window → Scan. Look at what channels nearby networks use. Change your router to a less congested channel (1, 6, or 11 for 2.4GHz — any channel on 5GHz).

Reset Network Settings

# Remove all network configs and start fresh
sudo rm /Library/Preferences/SystemConfiguration/com.apple.network.identification.plist
sudo rm /Library/Preferences/SystemConfiguration/com.apple.wifi.message-tracer.plist
sudo rm /Library/Preferences/SystemConfiguration/NetworkInterfaces.plist
sudo rm /Library/Preferences/SystemConfiguration/preferences.plist
sudo reboot

Check for macOS Update

Wi-Fi driver bugs are common in new macOS releases and fixed in point updates. System Settings → General → Software Update. If a known Wi-Fi bug exists, the fix is usually in the next .1 update.

Reset SMC (Intel Macs)

The SMC controls hardware including the Wi-Fi card. If nothing else works on an Intel Mac, reset it:

Shut down → hold Shift+Control+Option+Power for 7 seconds → release → power on.

Apple Silicon Macs: shut down and leave off for 30 seconds.

Check Wi-Fi Hardware

# Check if Wi-Fi hardware is detected
system_profiler SPAirPortDataType | head -20

# Check for hardware errors
log show --predicate 'subsystem == "com.apple.wifi"' --last 1h | grep -i error | head -20

If Wi-Fi does not appear at all and the menu bar shows no Wi-Fi icon, the hardware may have failed. On MacBooks this sometimes happens after a drop or liquid damage.
