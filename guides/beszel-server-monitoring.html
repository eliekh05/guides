Beszel — Lightweight Server Monitoring

Beszel is a self-hosted server monitoring dashboard. It is lighter than Prometheus+Grafana and simpler to set up — a single binary hub collects metrics from agents running on your servers and displays them in a clean web UI.

Architecture

  • Hub — the web UI and data collection server. Run this once.
  • Agent — lightweight process running on each server you want to monitor. Connects back to the hub.

Install the Hub

mkdir -p ~/beszel && cd ~/beszel

cat > docker-compose.yml << 'YAML'
services:
  beszel:
    image: henrygd/beszel:latest
    container_name: beszel
    restart: unless-stopped
    ports:
      - 8090:8090
    volumes:
      - ./beszel_data:/beszel_data
YAML

docker compose up -d

Open http://YOUR_SERVER_IP:8090 and create your admin account.

Install the Agent on Each Server

In the Beszel web UI: Systems → Add System → copy the agent install command. It looks like:

curl -sL https://raw.githubusercontent.com/henrygd/beszel/main/supplemental/scripts/install-agent.sh \
  -o install-agent.sh && bash install-agent.sh -p 45876 -k "YOUR_PUBLIC_KEY"

Run this on each server you want to monitor. The agent installs as a systemd service and starts automatically.

What It Monitors

  • CPU usage (overall and per core)
  • Memory and swap usage
  • Disk usage per filesystem
  • Network bandwidth in/out per interface
  • Disk I/O read/write
  • Docker container status and resource usage
  • System temperature (where available)

Alerts

Beszel supports alerts for CPU, memory, disk, network, and temperature thresholds. Configure per system in the web UI.

Notification channels: email, Slack, Discord, Telegram, Pushover, ntfy, and any webhook.

Historical Data

Data is stored in SQLite. By default it retains:

  • 1-minute granularity for the last hour
  • 10-minute granularity for the last 24 hours
  • 1-hour granularity for the last 30 days
  • Daily summaries indefinitely
