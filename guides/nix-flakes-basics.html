Nix Flakes — Modern Nix Package Management

Flakes are the modern way to use Nix — they make package versions reproducible and eliminate the need for nix-channel. If you are learning Nix in 2026, start with flakes.

Enable Flakes

# Add to /etc/nix/nix.conf or ~/.config/nix/nix.conf
echo "experimental-features = nix-command flakes" | sudo tee -a /etc/nix/nix.conf

# Restart nix daemon
sudo systemctl restart nix-daemon   # Linux
# On macOS the daemon restarts automatically

Run a Package Without Installing

# Run a command from nixpkgs without installing it
nix run nixpkgs#cowsay -- "hello"
nix run nixpkgs#htop
nix run nixpkgs#neovim

# Run a specific version
nix run nixpkgs/23.11#neovim

Start a Temporary Shell With Packages

# Open a shell with specific packages available
nix shell nixpkgs#nodejs nixpkgs#yarn

# Multiple packages
nix shell nixpkgs#python3 nixpkgs#python3Packages.requests

# Exit the shell to remove them
exit

Create a flake.nix

A flake.nix defines your project's dependencies reproducibly.

{
  description = "My project";

  inputs = {
    nixpkgs.url = "github:NixOS/nixpkgs/nixos-unstable";
    flake-utils.url = "github:numtide/flake-utils";
  };

  outputs = { self, nixpkgs, flake-utils }:
    flake-utils.lib.eachDefaultSystem (system:
      let
        pkgs = nixpkgs.legacyPackages.${system};
      in {
        devShells.default = pkgs.mkShell {
          packages = with pkgs; [
            nodejs_20
            yarn
            git
          ];
          shellHook = ''
            echo "Dev environment ready"
          '';
        };
      }
    );
}
# Enter the dev shell defined in flake.nix
nix develop

# direnv integration — auto-activate when entering directory
echo "use flake" > .envrc
direnv allow

Update Flake Inputs

# Update all inputs to latest
nix flake update

# Update a specific input
nix flake update nixpkgs

# Check what would be updated
nix flake metadata

The flake.lock File

flake.lock pins every dependency to an exact commit. Commit it to Git — anyone who checks out your project gets the exact same packages. This is the main advantage of flakes over channels.

Search for Packages

# Search nixpkgs
nix search nixpkgs neovim
nix search nixpkgs#python

# Or use the web search
# https://search.nixos.org/packages

Show Package Info

nix eval nixpkgs#neovim.version
nix show-derivation nixpkgs#neovim

Common Flake Commands

nix flake show          # show outputs of current flake
nix flake check         # validate the flake
nix flake metadata      # show input versions
nix build               # build the default package
nix build .#myPackage   # build a specific output

Home Manager with Flakes

{
  inputs = {
    nixpkgs.url = "github:NixOS/nixpkgs/nixos-unstable";
    home-manager = {
      url = "github:nix-community/home-manager";
      inputs.nixpkgs.follows = "nixpkgs";
    };
  };

  outputs = { nixpkgs, home-manager, ... }: {
    homeConfigurations."username" = home-manager.lib.homeManagerConfiguration {
      pkgs = nixpkgs.legacyPackages.x86_64-linux;
      modules = [ ./home.nix ];
    };
  };
}
# Apply home-manager config
home-manager switch --flake .#username
