Automate macOS with Shortcuts and Automator

macOS has two built-in automation tools — Shortcuts (modern, replaces Automator for most tasks) and Automator (still useful for folder actions and legacy workflows). Both can be combined with launchd for scheduled automation.

Shortcuts on macOS

Shortcuts arrived on macOS in Monterey (2021). It is the same app as iOS Shortcuts — cross-platform automation with a visual block editor.

Create a Shortcut

  1. Open Shortcuts app (Spotlight → Shortcuts)
  2. Click + to create a new shortcut
  3. Search for actions in the right panel and drag them in
  4. Connect blocks to build a workflow

Run Shortcuts from Terminal

# Run a shortcut by name
shortcuts run "My Shortcut Name"

# Run with input
echo "some text" | shortcuts run "Process Text"

# List all shortcuts
shortcuts list

Schedule a Shortcut with launchd

nano ~/Library/LaunchAgents/com.yourname.shortcut.plist
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN"
  "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
  <key>Label</key>
  <string>com.yourname.shortcut</string>
  <key>ProgramArguments</key>
  <array>
    <string>/usr/bin/shortcuts</string>
    <string>run</string>
    <string>My Shortcut Name</string>
  </array>
  <key>StartCalendarInterval</key>
  <dict>
    <key>Hour</key><integer>8</integer>
    <key>Minute</key><integer>0</integer>
  </dict>
</dict>
</plist>
launchctl load ~/Library/LaunchAgents/com.yourname.shortcut.plist

Automator

Automator is older but still the best tool for Folder Actions — automatically processing files when they are added to a folder.

Create a Folder Action

  1. Open Automator → New Document → Folder Action
  2. At the top, choose which folder to watch
  3. Add actions — common uses: convert images, rename files, move to another folder, run a script
  4. Save the workflow
  5. Right-click the folder in Finder → Quick Actions → Folder Action Setup → enable it

Run AppleScript from Automator

Add a "Run AppleScript" action to do anything the GUI can do:

on run {input, parameters}
  tell application "Safari"
    activate
    open location "https://example.com"
  end tell
  return input
end run

Run Shell Script from Automator

Add a "Run Shell Script" action. Set "Pass input" to "as arguments" to process files dropped onto it:

#!/bin/bash
for f in "$@"; do
  # Process each file
  ffmpeg -i "$f" "${f%.mp4}.mp3"
done

Useful Automation Ideas

  • Folder Action on Downloads — auto-move PDFs to a specific folder, rename screenshots
  • Scheduled Shortcut — daily backup of specific folders to an external drive
  • Shortcut — resize and compress images in a folder with one click
  • Shortcut — daily summary of calendar events sent as a notification
  • Automator — batch rename files with a consistent naming pattern

Script Editor for AppleScript

# Run AppleScript from terminal
osascript -e 'tell application "Finder" to empty trash'

# Run an AppleScript file
