Install Rocky Linux

Rocky Linux is a community enterprise Linux distribution — a free, binary-compatible replacement for Red Hat Enterprise Linux (RHEL). It is the successor to CentOS and is used in enterprise environments, scientific computing, and anywhere that requires long-term stability with 10-year support cycles.

Current Version

Rocky Linux 9.x (based on RHEL 9) is the current release, supported until May 2032. Rocky Linux 8.x is also supported until May 2029.

Download

Go to https://rockylinux.org/download and choose:

  • DVD ISO — full offline installer, includes all packages
  • Boot ISO — minimal, downloads packages during install (needs internet)
  • Minimal ISO — command line only, no GUI

Install

Flash to USB with balenaEtcher and boot. Rocky uses the Anaconda installer.

Installation Destination: Select your disk. Automatic partitioning is fine for most use cases. For servers, consider separating /home, /var, and /tmp.

Software Selection:

  • Server with GUI — GNOME desktop
  • Server — command line only (recommended for servers)
  • Minimal Install — absolute minimum
  • Workstation — desktop workstation with productivity apps

Root Password: Set a strong root password or create an admin user during install.

First Steps After Install

# Update all packages
sudo dnf update -y

# Install EPEL (Extra Packages for Enterprise Linux)
sudo dnf install epel-release -y
sudo dnf update -y

# Install common tools
sudo dnf install vim curl wget git htop tmux -y

# Enable and start firewall
sudo systemctl enable --now firewalld
sudo firewall-cmd --list-all

Enable PowerTools / CRB Repository

Some packages require the CodeReady Builder (CRB) repository, previously called PowerTools:

sudo dnf config-manager --set-enabled crb

Install Nginx or Apache

# Nginx
sudo dnf install nginx -y
sudo systemctl enable --now nginx
sudo firewall-cmd --permanent --add-service=http
sudo firewall-cmd --permanent --add-service=https
sudo firewall-cmd --reload

# Apache
sudo dnf install httpd -y
sudo systemctl enable --now httpd

SELinux

Rocky Linux ships with SELinux enforcing by default. This is a security feature — do not disable it unless you know why.

# Check SELinux status
getenforce

# See SELinux denials
sudo ausearch -m avc -ts recent | audit2why

# Allow a specific port for a service
sudo semanage port -a -t http_port_t -p tcp 8080

# Restore default file contexts
sudo restorecon -Rv /var/www/html/
