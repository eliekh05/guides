tmux — Terminal Multiplexer

tmux lets you run multiple terminal sessions inside one window, detach from them, and reattach later. Essential for remote servers — if your SSH connection drops, your processes keep running inside tmux.

Install

sudo apt install tmux      # Ubuntu/Debian
sudo dnf install tmux      # Fedora/RHEL
sudo pacman -S tmux        # Arch
brew install tmux           # macOS

Core Concept

tmux has three levels: sessions → windows → panes. A session contains windows (like browser tabs). A window contains panes (split terminal areas). The prefix key Ctrl+B precedes every tmux command.

Essential Commands

# Start a new session
tmux

# Start a named session
tmux new -s mysession

# List sessions
tmux ls

# Attach to a session
tmux attach -t mysession
tmux a        # attach to last session

# Detach from session (keeps it running)
Ctrl+B  d

# Kill a session
tmux kill-session -t mysession

Pane Shortcuts

ShortcutAction
Ctrl+B %Split pane vertically
Ctrl+B "Split pane horizontally
Ctrl+B ArrowMove between panes
Ctrl+B zZoom pane to full window (toggle)
Ctrl+B xClose current pane
Ctrl+B qShow pane numbers
Ctrl+B {Swap pane left
Ctrl+B }Swap pane right

Window Shortcuts

ShortcutAction
Ctrl+B cCreate new window
Ctrl+B nNext window
Ctrl+B pPrevious window
Ctrl+B [0-9]Switch to window by number
Ctrl+B ,Rename current window
Ctrl+B &Close current window
Ctrl+B wList all windows

Copy Mode (Scroll and Select Text)

Ctrl+B [        # enter copy mode
Arrow keys      # scroll
Space           # start selection
Enter           # copy selection
Ctrl+B ]        # paste

~/.tmux.conf — Essential Config

# Change prefix from Ctrl+B to Ctrl+A (like screen)
unbind C-b
set -g prefix C-a
bind C-a send-prefix

# Enable mouse support
set -g mouse on

# Start windows and panes from 1 not 0
set -g base-index 1
setw -g pane-base-index 1

# Increase scrollback buffer
set -g history-limit 10000

# Status bar
set -g status-style bg=black,fg=green
set -g status-right '%H:%M %d-%b'

# Split panes with | and -
bind | split-window -h -c "#{pane_current_path}"
bind - split-window -v -c "#{pane_current_path}"

# Reload config
bind r source-file ~/.tmux.conf \; display "Reloaded"
# Apply config without restarting
tmux source ~/.tmux.conf

Keep SSH Sessions Alive

# Start tmux on your server
ssh user@server
tmux new -s work

# Run your long-running commands
# If SSH drops — reconnect and:
ssh user@server
tmux attach -t work    # everything is still running

Send Commands to All Panes

# Synchronize input to all panes in window
Ctrl+B :setw synchronize-panes on

# Type a command — it goes to all panes simultaneously
# Turn off when done
Ctrl+B :setw synchronize-panes off

Scripted Session Setup

#!/bin/bash
# Create a dev environment with one command
tmux new-session -d -s dev -x 220 -y 50
tmux rename-window -t dev:1 'editor'
tmux send-keys -t dev:1 'nvim .' Enter
tmux new-window -t dev:2 -n 'server'
tmux send-keys -t dev:2 'npm run dev' Enter
tmux new-window -t dev:3 -n 'git'
tmux attach-session -t dev
