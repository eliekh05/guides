Vim Basics — Editing Files in the Terminal

Vim is a terminal text editor available on virtually every Linux/Unix system. It has a steep learning curve but once you know the basics, you can edit any file on any server without needing a GUI.

Open a File

vim filename.txt         # open or create a file
vim /etc/nginx/nginx.conf    # edit a system file (use sudo if needed)
sudo vim /etc/hosts

The Most Important Concept — Modes

Vim has modes. You cannot just start typing. When you open a file you are in Normal mode.

ModePurposeHow to enter
NormalNavigate, copy, delete, run commandsPress Esc
InsertType textPress i
VisualSelect textPress v
CommandSave, quit, search, replacePress : (colon)

The Bare Minimum — Open, Edit, Save, Quit

  1. Open a file: vim file.txt
  2. Press i to enter Insert mode
  3. Type your changes
  4. Press Esc to return to Normal mode
  5. Type :wq and press Enter to save and quit

Saving and Quitting

:w        save
:q        quit (fails if unsaved changes)
:wq       save and quit
:x        save and quit (same as :wq)
:q!       quit WITHOUT saving — discard all changes
:w !sudo tee %    save a file you opened without sudo

Moving Around (Normal Mode)

h j k l    left, down, up, right (or use arrow keys)
w          jump forward one word
b          jump backward one word
0          go to start of line
$          go to end of line
gg         go to first line of file
G          go to last line of file
:50        go to line 50
Ctrl+f     page down
Ctrl+b     page up

Entering Insert Mode

i    insert before cursor
a    insert after cursor
o    open new line below and insert
O    open new line above and insert
A    insert at end of current line
I    insert at beginning of current line

Editing in Normal Mode

dd       delete (cut) current line
yy       yank (copy) current line
p        paste below current line
P        paste above current line
u        undo
Ctrl+r   redo
x        delete character under cursor
dw       delete word
D        delete from cursor to end of line
cw       change word (delete word and enter insert mode)

Search and Replace

/pattern      search forward for pattern
?pattern      search backward
n             next match
N             previous match

# Replace all occurrences on current line
:s/old/new/g

# Replace all occurrences in entire file
:%s/old/new/g

# Replace with confirmation prompt
:%s/old/new/gc

Visual Mode — Select Text

v        character-by-character selection
V        select whole lines
Ctrl+v   block/column selection

# After selecting:
d        delete selection
y        yank (copy) selection
>        indent
<        unindent

Useful Commands

:set number        show line numbers
:set nonumber      hide line numbers
:set paste         disable auto-indent (useful when pasting)
:syntax on         enable syntax highlighting
:noh               clear search highlight

Exit Vim — The Classic Problem

Esc Esc :q! Enter    # quit without saving — always works
