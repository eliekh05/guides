systemd Timers — The Modern Alternative to cron

systemd timers are the recommended way to schedule tasks on modern Linux systems. Unlike cron, timers integrate with the systemd journal, track missed runs when the machine was off, and can depend on other services.

How It Works

Every timer needs two files: a .timer unit (defines when to run) and a .service unit (defines what to run). They share the same base name.

Create a Timer (System-Wide)

Create the service file:

sudo nano /etc/systemd/system/mybackup.service
[Unit]
Description=My Backup Script

[Service]
Type=oneshot
ExecStart=/usr/local/bin/backup.sh
User=youruser

Create the timer file:

sudo nano /etc/systemd/system/mybackup.timer
[Unit]
Description=Run My Backup Daily

[Timer]
OnCalendar=daily
Persistent=true
AccuracySec=1h

[Install]
WantedBy=timers.target

Enable and start:

sudo systemctl daemon-reload
sudo systemctl enable --now mybackup.timer

OnCalendar Syntax

OnCalendar=daily              # every day at midnight
OnCalendar=weekly             # every Monday at midnight
OnCalendar=monthly            # first of every month at midnight
OnCalendar=hourly             # every hour
OnCalendar=*:0/15             # every 15 minutes
OnCalendar=Mon..Fri 09:00:00  # weekdays at 9am
OnCalendar=Sat,Sun 12:00:00   # weekends at noon
OnCalendar=*-*-* 02:30:00     # every day at 02:30
OnCalendar=2026-06-01 00:00:00 # specific date

Validate any calendar expression:

systemd-analyze calendar "Mon..Fri 09:00:00"

OnBootSec and OnUnitActiveSec

[Timer]
# Run 5 minutes after boot
OnBootSec=5min

# Then run every hour after that
OnUnitActiveSec=1h

Persistent — Catch Up Missed Runs

Persistent=true tells systemd to run the timer immediately if it missed its scheduled time (e.g. the machine was off). This is the most important difference from cron — a cron job simply does not run if the machine was off at the scheduled time.

User Timers (No sudo)

# Place in ~/.config/systemd/user/
mkdir -p ~/.config/systemd/user

# Create mybackup.service and mybackup.timer there
# Then:
systemctl --user daemon-reload
systemctl --user enable --now mybackup.timer

# Run at boot even without login
loginctl enable-linger $(whoami)

Manage and Monitor Timers

systemctl list-timers                    # list all timers and next trigger
systemctl list-timers --all              # include inactive timers
systemctl status mybackup.timer          # timer status
systemctl status mybackup.service        # last run result
journalctl -u mybackup.service           # logs from all runs
journalctl -u mybackup.service -n 50     # last 50 lines
systemctl stop mybackup.timer            # pause
systemctl start mybackup.timer           # resume
systemctl disable mybackup.timer         # disable permanently

Run a Timer Immediately (For Testing)

systemctl start mybackup.service    # runs the service now, not the timer
