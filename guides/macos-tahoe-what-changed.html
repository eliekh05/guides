macOS Tahoe (macOS 26) — What Changed

macOS Tahoe is Apple's macOS release for 2025, officially known as macOS 26. Released September 2025. This guide covers the most significant changes that affect how you use your Mac day to day.

Supported Macs

  • MacBook Air: 2020 and later (M1+), 2019 MacBook Air removed
  • MacBook Pro: 2019 and later
  • Mac mini: 2020 and later
  • Mac Studio: all models
  • Mac Pro: 2019 and later
  • iMac: 2019 and later

Liquid Glass Design

The biggest visual change since macOS Big Sur. UI elements throughout the system now use a translucent, refractive glass material — the menu bar, sidebars, toolbars, and dock have a new look. Controls appear more physical and three-dimensional.

If you prefer the old look, reduced transparency helps: System Settings → Accessibility → Display → Reduce transparency.

Apple Intelligence

macOS Tahoe expands Apple Intelligence features significantly:

  • Writing Tools — available in any text field system-wide. Rewrite, proofread, and summarize selected text via right-click → Writing Tools.
  • Genmoji — generate custom emoji from a text description
  • Image Playground — generate images in Messages and Notes
  • Priority notifications — AI summarizes and prioritizes notifications
  • Siri improvements — deeper system control, can perform multi-step actions

Apple Intelligence requires Apple Silicon (M1 or later) and is processed on-device for most features.

Safari 19

  • Web Eraser — permanently remove elements from any webpage (ads, sidebars, recommendations)
  • Reader mode improvements — better formatting on more sites
  • Passwords app integration with passkeys
  • Page translation expanded to more languages

iPhone Mirroring Improvements

iPhone Mirroring now supports drag and drop between iPhone and Mac — drag a file from Finder and drop it directly into an iPhone app. Also supports iPhone widgets on the Mac desktop.

Continuity Camera Updates

Use your iPhone as a Mac webcam with improved background segmentation, Studio Light (professional lighting effect), and Presenter Overlay (shows you in front of your screen content during video calls).

System Settings Changes

  • Privacy & Security reorganised — easier to find app permissions
  • New Focus filters section
  • Battery settings moved to top level (no longer nested under hardware)

Known Issues at Launch

  • Some third-party menu bar apps need updates for the new menu bar design
  • Virtual machines (Parallels, VMware) need updates for full compatibility
  • Some older Electron apps have rendering issues with Liquid Glass

Should You Upgrade

Wait 2–4 weeks after release for the first point update (macOS 26.1) if you depend on specific professional apps — confirm compatibility with critical software before upgrading. For most users on Apple Silicon, Tahoe is stable and the features are worth it.
