Fix iCloud Drive Sync Issues

iCloud Drive sync problems fall into a few categories — files stuck downloading, uploads stalling, or the sync never completing. Here is how to diagnose and fix each one.

Check iCloud Server Status First

Go to https://www.apple.com/support/systemstatus/ and confirm iCloud Drive shows green. If it is yellow or red, wait for Apple to resolve it — nothing you do locally will fix a server-side outage.

Check Available iCloud Storage

System Settings → Apple ID → iCloud → Manage Account Storage. If you are at or near the limit, sync stops until you free space or upgrade. Files will show the cloud icon indefinitely.

Restart the iCloud Sync Daemon

killall bird

iCloud restarts automatically within seconds. Wait 1–2 minutes and check if sync resumes. This fixes the majority of stuck sync issues.

Force Download Stuck Files

# Force download everything in iCloud Drive
brctl download ~/Library/Mobile\ Documents/com~apple~CloudDocs/

# Download a specific file
brctl download /path/to/file

Or in Finder: right-click a file showing the cloud icon → Download Now.

Check Sync Status in Detail

# Watch iCloud sync activity in real time
brctl log --wait --shorten

# Check what is currently syncing
brctl status

Reset iCloud Drive Cache

killall bird
rm -rf ~/Library/Application\ Support/CloudDocs/session/

iCloud rebuilds the session cache. Allow several minutes for sync to resume.

Files on Mac But Not on iPhone

  1. Confirm iCloud Drive is enabled on iPhone: Settings → [your name] → iCloud → iCloud Drive → On
  2. Open the Files app → iCloud Drive and pull down to refresh
  3. Check the file is not in a folder that is excluded from iCloud sync

Desktop and Documents Not Syncing

System Settings → Apple ID → iCloud → iCloud Drive → Options → confirm Desktop and Documents Folders is checked. If you just enabled this, allow 10–30 minutes for the initial upload of existing files.

Disable and Re-enable iCloud Drive

Last resort — only do this if nothing else works:

  1. System Settings → Apple ID → iCloud → iCloud Drive → Off
  2. Choose Keep a Copy when prompted (not Remove from Mac)
  3. Restart your Mac
  4. Re-enable iCloud Drive

Monitor iCloud Daemon Logs

log stream --predicate 'subsystem == "com.apple.bird"' --level debug 2>&1 | head -50
