Fix Windows Update Stuck or Failing

Windows Update gets stuck for several reasons — corrupted update cache, a failed previous update, service not running, or disk space issues. Work through these steps in order.

Basic Checks First

  • You need at least 10–20 GB free space for updates to download and install
  • The Windows Update service must be running
  • Date and time must be correct — a wrong system clock breaks update downloads
# Check date and time
date
# If wrong: Settings → Time & Language → Set time automatically → On

# Check available disk space
Get-PSDrive C | Select Used, Free

Run the Windows Update Troubleshooter

Settings → System → Troubleshoot → Other troubleshooters → Windows Update → Run

This fixes the most common issues automatically.

Restart Windows Update Services

# Run PowerShell as Administrator
net stop wuauserv
net stop cryptSvc
net stop bits
net stop msiserver

# Clear the update cache
Remove-Item -Path "C:\Windows\SoftwareDistribution" -Recurse -Force
Remove-Item -Path "C:\Windows\System32\catroot2" -Recurse -Force

# Restart services
net start wuauserv
net start cryptSvc
net start bits
net start msiserver

Try Windows Update again after this.

Fix Corrupted System Files

# Scan and repair system files
sfc /scannow

# Fix Windows component store corruption
DISM /Online /Cleanup-Image /CheckHealth
DISM /Online /Cleanup-Image /ScanHealth
DISM /Online /Cleanup-Image /RestoreHealth

# Restart after DISM completes, then run sfc again
sfc /scannow

Manually Download and Install a Stuck Update

Find the update KB number from Windows Update (shown in the error or update history). Go to https://catalog.update.microsoft.com, search for the KB number, download and install manually.

Reset Windows Update Components Completely

# Run all of these in PowerShell as Administrator
Stop-Service wuauserv, cryptSvc, bits, msiserver -Force

Rename-Item "$env:SystemRoot\SoftwareDistribution" "SoftwareDistribution.bak" -ErrorAction SilentlyContinue
Rename-Item "$env:SystemRoot\System32\catroot2" "catroot2.bak" -ErrorAction SilentlyContinue

netsh winsock reset
netsh winsock reset proxy

Start-Service wuauserv, cryptSvc, bits, msiserver

Update Stuck at 0% Downloading

This is usually a BITS (Background Intelligent Transfer Service) issue:

sc.exe sdset bits D:(A;;CCLCSWRPWPDTLOCRRC;;;SY)(A;;CCDCLCSWRPWPDTLOCRSDRCWDWO;;;BA)(A;;CCLCSWLOCRRC;;;AU)(A;;CCLCSWRPWPDTLOCRRC;;;PU)

Update Stuck Installing at a Percentage

If the update shows e.g. "30% complete" and does not move for more than 2 hours:

  1. Hard reboot (hold power button)
  2. Windows will attempt to roll back the failed update on next boot
  3. Once back in Windows, run the DISM and sfc commands above
  4. Try the update again

Check Windows Update Log

# Generate readable log
Get-WindowsUpdateLog

# Open it
notepad $env:USERPROFILE\Desktop\WindowsUpdate.log

Search for "FAILED" or "Error" to find the specific failure point.
