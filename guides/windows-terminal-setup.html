Windows Terminal — Setup and Customization

Windows Terminal is Microsoft's modern terminal — it supports multiple tabs, panes, GPU rendering, and full Unicode. It replaced the old Command Prompt and PowerShell windows and is the best terminal experience on Windows.

Install

# Via winget
winget install Microsoft.WindowsTerminal

# Or download from Microsoft Store — search "Windows Terminal"

Set as Default Terminal

Settings → Startup → Default terminal application → Windows Terminal

After this, clicking "Open in Terminal" in File Explorer, or launching CMD or PowerShell, opens in Windows Terminal instead of the old windows.

Install Oh My Posh (Prompt Customization)

# Install Oh My Posh
winget install JanDeDobbeleer.OhMyPosh

# Install a Nerd Font (required for icons)
oh-my-posh font install

Select a font (Meslo LGM NF is popular), then set it in Windows Terminal settings → Profiles → Defaults → Font face.

# Add to PowerShell profile
notepad $PROFILE

# Add this line:
oh-my-posh init pwsh | Invoke-Expression

Install PSReadLine (Better PowerShell Experience)

# Install
Install-Module PSReadLine -Force

# Add to $PROFILE:
Set-PSReadLineOption -PredictionSource History
Set-PSReadLineOption -PredictionViewStyle ListView
Set-PSReadLineKeyHandler -Key Tab -Function MenuComplete

PSReadLine adds inline command history predictions (type the start of a previous command, press right arrow to complete it) and tab completion with a menu.

settings.json Key Options

# Open settings.json via:
# Settings → Open JSON file (bottom left)

{
  "defaultProfile": "{PowerShell GUID}",
  "copyOnSelect": true,
  "profiles": {
    "defaults": {
      "font": {
        "face": "MesloLGM Nerd Font",
        "size": 12
      },
      "opacity": 95,
      "useAcrylic": true,
      "colorScheme": "One Half Dark",
      "cursorShape": "filledBox",
      "padding": "8"
    }
  }
}

Add Git Bash as a Profile

  1. Settings → Add a new profile → New empty profile
  2. Name: Git Bash
  3. Command line: C:\Program Files\Git\bin\bash.exe --login -i
  4. Starting directory: %USERPROFILE%

Add WSL as a Profile

If WSL is installed, Windows Terminal auto-detects it and adds it as a profile. If not:

  1. Settings → Add a new profile
  2. Command line: wsl.exe -d Ubuntu

Color Schemes

Built-in schemes: One Half Dark, Campbell, Solarized Dark, Tango Dark. Browse community themes at https://windowsterminalthemes.dev — copy the JSON and add to schemes array in settings.json.
