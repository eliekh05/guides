Fix MacBook Overheating and Fan Always Running

MacBooks regulate temperature by throttling the CPU and spinning the fan. If your Mac is constantly hot or the fan never stops, something is generating excessive heat.

Identify What Is Generating Heat

Open Activity Monitor → CPU tab. Sort by % CPU descending. Anything consistently above 50% CPU while you are not actively doing something is a problem.

Common causes:

  • kernel_task — macOS deliberately limiting CPU to cool the system (symptom, not cause)
  • mds_stores / mdworker — Spotlight indexing (temporary, finishes in a few hours)
  • Google Chrome Helper (Renderer) — Chrome tabs and extensions
  • Electron apps (Slack, VS Code, Discord) running multiple background processes
  • Antivirus software scanning in real time
  • Video calls (Zoom, Teams) with virtual backgrounds

Check CPU Temperature

# Intel Macs
sudo powermetrics -n 1 --samplers smc | grep -i "CPU die temperature"

# Apple Silicon — check thermal pressure
sudo powermetrics -n 1 --samplers thermal | grep -i pressure

Above 90°C on Intel is concerning. Apple Silicon runs hotter by design — up to 95°C under load is normal.

Reset SMC (Intel Macs)

The SMC controls fan speed and thermal management. A corrupted SMC can cause fans to spin at full speed or not at all.

MacBook with T2 chip: Shut down → hold Shift+Control+Option (left side) + Power for 7 seconds → release all → power on.

Older Intel MacBook (removable battery): Remove battery → hold Power for 5 seconds → reinsert battery → power on.

Apple Silicon: No SMC. Shut down and leave off for 30 seconds.

Reset NVRAM

# Intel Mac: restart and hold Cmd+Option+P+R until second startup chime
# Apple Silicon: NVRAM resets automatically, no action needed

Check for Thermal Paste Degradation (Intel Macs)

On Intel MacBooks older than 4–5 years, the thermal paste between the CPU and heat sink dries out. This is a hardware issue — the Mac will run hot under any load. A repair shop can reterminate it for $50–$100 and the improvement is usually dramatic (10–20°C reduction).

Prevent Overheating Day-to-Day

  • Do not use on fabric surfaces (bed, sofa) — blocks the vents on the bottom
  • Use Safari instead of Chrome for everyday browsing
  • Quit Slack when not actively using it — use the web version or check periodically
  • Disable virtual backgrounds in video calls
  • Keep macOS updated — thermal management improvements ship with updates
  • Use Low Power Mode in System Settings → Battery when doing light work

Manual Fan Control (Intel Only)

Apps like Macs Fan Control allow manual fan speed adjustment. Useful for getting the Mac cool quickly before a CPU-intensive task. Not recommended for permanent use — macOS's thermal management is conservative for good reason. Apple Silicon Macs do not expose fan control APIs to third-party apps.
