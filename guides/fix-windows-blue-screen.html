Fix Blue Screen of Death (BSOD) on Windows

A blue screen means Windows hit a critical error it couldn't recover from. The stop code on the screen tells you where to look. Most BSODs are caused by bad drivers, failing hardware, or corrupted system files.

Read the Stop Code

The stop code appears on the blue screen itself. Common ones:

Stop CodeLikely Cause
IRQL_NOT_LESS_OR_EQUALBad driver, usually recently installed
PAGE_FAULT_IN_NONPAGED_AREAFaulty RAM or bad driver
SYSTEM_SERVICE_EXCEPTIONDriver or software bug
DRIVER_POWER_STATE_FAILUREDriver not handling sleep/wake properly
CRITICAL_PROCESS_DIEDEssential Windows process crashed — often corrupted system files
MEMORY_MANAGEMENTRAM problem
NTFS_FILE_SYSTEMFailing hard drive
DPC_WATCHDOG_VIOLATIONDriver taking too long — often SSD driver issue

View Crash Logs

Win+R → eventvwr → Windows Logs → System → filter for "Critical"

Or use WhoCrashed (free tool) — it reads the memory dump and tells you which driver caused the crash in plain English. Download from resplendence.com.

Check for Driver Issues

If a BSOD started after installing new software or a driver update:

  1. Boot into Safe Mode — hold Shift while clicking Restart
  2. Device Manager → right-click the recently updated driver → Roll Back Driver
  3. Or uninstall it entirely and reinstall a previous version
# Run Driver Verifier to stress-test drivers (causes deliberate crashes to identify bad ones)
# Only do this if you can afford a few crashes
verifier    # in Run dialog

Repair System Files

# Open Command Prompt as Administrator
sfc /scannow

# If sfc finds issues it can't fix, run DISM first
DISM /Online /Cleanup-Image /RestoreHealth
sfc /scannow

Test Your RAM

Win+R → mdsched → restart and run memory test

Let it run — the extended test takes a couple of hours. If it finds errors, your RAM is failing and needs replacing. Try reseating the RAM sticks first — remove and firmly press back in.

Check the Hard Drive

# Check disk health
# Open Command Prompt as Administrator
chkdsk C: /f /r /x

# This requires a restart to run on the system drive
# It will scan and fix filesystem errors on next boot

Download CrystalDiskInfo (free) to check the S.M.A.R.T. data on your drive — if it shows "Caution" or "Bad" status, the drive is failing and needs replacing soon.

Check for Overheating

BSODs during heavy tasks (gaming, video encoding) often mean thermal throttling or shutdown:

Download HWiNFO64 → run sensors-only mode → check CPU and GPU temperatures under load

CPU over 95°C or GPU over 90°C under sustained load is too hot. Clean the fans and heatsinks, reapply thermal paste if it's been a few years.

Undo Recent Changes

Start → "Create a restore point" → System Restore → pick a date before BSODs started

If Windows Won't Boot at All

  1. Force shut down 3 times in a row during startup — Windows enters Automatic Repair
  2. Advanced Options → Startup Repair
  3. Advanced Options → Command Prompt → run sfc /scannow and chkdsk
  4. Last resort: Reset This PC (keeps files) or reinstall Windows
