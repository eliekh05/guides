macOS Terminal Tips and Tricks

Practical terminal tricks for macOS that save time day to day — most people discover these years in, if at all.

Open Finder from Terminal

open .                    # open current directory in Finder
open ~/Downloads          # open specific folder
open -a "TextEdit" file   # open file with specific app
open -a "Google Chrome" https://example.com

Open Terminal in Current Finder Folder

System Settings → Privacy & Security → Full Disk Access → enable Terminal. Then in Finder: right-click a folder → New Terminal at Folder (or drag folder into Terminal window).

Copy Terminal Output to Clipboard

# Copy output of any command to clipboard
cat file.txt | pbcopy
ls -la | pbcopy
pwd | pbcopy

# Paste from clipboard
pbpaste
pbpaste > newfile.txt

Quick Look a File from Terminal

qlmanage -p file.jpg       # opens Quick Look preview
# or
open -R file.jpg           # reveal in Finder

Say Command — Text to Speech

say "Hello"
say -v Samantha "Your script has finished"
say -v Daniel "Build complete"    # British voice

# List available voices
say -v ?

# Useful for long scripts
./long-build.sh && say "Build complete" || say "Build failed"

Network Utilities

# Flush DNS cache
sudo dscacheutil -flushcache && sudo killall -HUP mDNSResponder

# Show all network interfaces
networksetup -listallnetworkservices

# Get IP address
ipconfig getifaddr en0      # Wi-Fi
ipconfig getifaddr en1      # Ethernet

# Show ARP table (devices on local network)
arp -a

System Information

# macOS version
sw_vers

# Hardware info
system_profiler SPHardwareDataType

# CPU info
sysctl -n machdep.cpu.brand_string

# Memory
sysctl hw.memsize | awk '{print $2/1024/1024/1024 " GB"}'

# Uptime
uptime

Spotlight from Terminal

# Search with mdfind (Spotlight in CLI)
mdfind -name "document.pdf"
mdfind "kind:pdf author:John"

# Find files modified today
mdfind -onlyin ~ 'kMDItemContentModificationDate >= $time.today'

Disable/Enable Desktop Gatekeeper for Scripts

# Remove quarantine from a downloaded app
xattr -rd com.apple.quarantine /Applications/App.app

# Check quarantine status
xattr -l /Applications/App.app

Set Default App for File Type

# Install duti (brew install duti)
# Set VS Code as default for .md files
duti -s com.microsoft.VSCode .md all

# Find app bundle ID
osascript -e 'id of app "Visual Studio Code"'

Caffeinate — Prevent Sleep

# Prevent sleep indefinitely
caffeinate

# Prevent sleep for 2 hours
caffeinate -t 7200

# Prevent sleep until a command finishes
caffeinate -i ./long-script.sh

# Prevent display sleep (not just system sleep)
caffeinate -d

Useful Aliases for ~/.zshrc

# Add to ~/.zshrc
alias ll='ls -laG'
alias ..='cd ..'
alias ...='cd ../..'
alias flushdns='sudo dscacheutil -flushcache && sudo killall -HUP mDNSResponder'
alias ip='ipconfig getifaddr en0'
alias pubkey='cat ~/.ssh/id_ed25519.pub | pbcopy && echo "Copied to clipboard"'
alias cleanup='find . -name ".DS_Store" -delete && find . -name "*.pyc" -delete'
