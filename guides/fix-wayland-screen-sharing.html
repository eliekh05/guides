Fix Screen Sharing on Wayland (Discord, Zoom, OBS)

Screen sharing on Wayland requires xdg-desktop-portal — a permission layer that apps use to request screen capture. Without the right portal implementation installed, screen sharing shows a black screen or fails entirely.

Check What Portal Is Installed

systemctl --user status xdg-desktop-portal
systemctl --user status xdg-desktop-portal-gnome    # if on GNOME
systemctl --user status xdg-desktop-portal-wlr      # if on wlroots (Sway, Hyprland)
systemctl --user status xdg-desktop-portal-hyprland # if on Hyprland

Install the Right Portal for Your Desktop

# GNOME
sudo apt install xdg-desktop-portal-gnome   # Ubuntu/Debian
sudo dnf install xdg-desktop-portal-gnome   # Fedora
sudo pacman -S xdg-desktop-portal-gnome     # Arch

# KDE Plasma
sudo apt install xdg-desktop-portal-kde
sudo pacman -S xdg-desktop-portal-kde

# Hyprland / wlroots (Sway, River, etc.)
sudo pacman -S xdg-desktop-portal-hyprland    # Arch
# or
sudo pacman -S xdg-desktop-portal-wlr         # Arch (older, for non-Hyprland wlroots)

Restart the Portal

systemctl --user restart xdg-desktop-portal
systemctl --user restart xdg-desktop-portal-gnome   # or your desktop's variant

Then restart the app you are trying to share from (Discord, Zoom, OBS).

Check for Conflicting Portals

Having multiple portal implementations installed can cause conflicts. Check:

systemctl --user list-units 'xdg-desktop-portal*'

You should have exactly one desktop-specific portal running alongside the base xdg-desktop-portal. If you have both xdg-desktop-portal-gnome and xdg-desktop-portal-wlr running, disable the one that does not match your desktop.

Discord Specifically

Discord on Wayland requires launching with a specific flag:

# Add to Discord launch options or create a wrapper:
discord --enable-features=UseOzonePlatform --ozone-platform=wayland

Or set the environment variable:

NIXOS_OZONE_WL=1 discord    # or
ELECTRON_OZONE_PLATFORM_HINT=auto discord

In Hyprland, add to your config:

env = ELECTRON_OZONE_PLATFORM_HINT,auto

OBS on Wayland

OBS requires PipeWire and the portal. Install:

sudo pacman -S obs-studio pipewire wireplumber
sudo apt install obs-studio pipewire wireplumber

In OBS: Sources → + → Screen Capture (PipeWire). A system dialog appears asking which window or screen to share — this is the portal working correctly.

Zoom on Wayland

# Launch Zoom with Wayland support
QT_QPA_PLATFORM=wayland zoom

Check PipeWire Is Running

systemctl --user status pipewire
systemctl --user status wireplumber    # or pipewire-media-session on older setups

If either is not running:

systemctl --user enable --now pipewire wireplumber
