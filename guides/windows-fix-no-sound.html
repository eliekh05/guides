Fix No Sound on Windows 11 and 10

No audio on Windows is almost always a driver issue, a muted device, or Windows routing sound to the wrong output. Work through these in order.

Check the Obvious First

  • Volume mixer isn't muted — right-click the speaker icon in the taskbar
  • The right output device is selected — click the speaker icon and make sure it shows your headphones or speakers
  • Cable is plugged into the right port (front panel vs rear, headphone jack vs line out)
  • Bluetooth headphones are connected and not connected to another device simultaneously

Check Sound Settings

  1. Right-click the speaker icon → Sound settings
  2. Under Output, make sure your speakers/headphones are selected
  3. Click the device and check the volume slider isn't at zero
  4. Click "Test" to see if sound plays

Run the Audio Troubleshooter

  1. Settings → System → Troubleshoot → Other troubleshooters
  2. Click Run next to "Playing Audio"
  3. Follow the steps — it fixes the most common issues automatically

Restart the Windows Audio Service

  1. Press Win+R → type services.msc → Enter
  2. Find "Windows Audio" → right-click → Restart
  3. Also restart "Windows Audio Endpoint Builder"
# Or from an admin command prompt
net stop audiosrv && net start audiosrv

Update or Reinstall Audio Drivers

  1. Right-click Start → Device Manager
  2. Expand "Sound, video and game controllers"
  3. Right-click your audio device → Update driver → Search automatically

If that doesn't work, uninstall the driver entirely (check "Delete the driver software for this device"), restart, and let Windows reinstall it automatically.

For better results, go directly to your motherboard or laptop manufacturer's website and download the latest Realtek, Intel, or AMD audio driver for your model.

Check Volume Mixer Per-App

Right-click speaker icon → Open volume mixer

Some apps can be individually muted here even when the system volume is up. Check if the specific app you're trying to hear has a separate muted slider.

Set Default Audio Device

  1. Right-click speaker icon → Sound settings → More sound settings
  2. Playback tab — right-click your device → Set as Default Device
  3. Also set it as Default Communication Device

Disable Audio Enhancements

Some systems have audio processing that conflicts with certain hardware:

  1. Sound settings → More sound settings → Playback
  2. Right-click your device → Properties → Advanced
  3. Uncheck "Enable audio enhancements"

HDMI / DisplayPort Audio

If you're using a monitor with built-in speakers via HDMI or DisplayPort, Windows may not pick it as the output automatically:

  1. Sound settings → More sound settings → Playback
  2. Look for an entry named after your monitor or "HDMI Output"
  3. Right-click → Enable (if it's greyed out)
  4. Right-click → Set as Default Device

System Restore

If audio was working before and stopped after an update:

Start → "Create a restore point" → System Restore → choose a date before it broke
