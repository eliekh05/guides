Vaultwarden — Self-Hosted Password Manager

Vaultwarden is an unofficial, lightweight Bitwarden server you run yourself. You get all the Bitwarden apps and browser extensions, full end-to-end encryption, and your vault never touches someone else's servers. The official Bitwarden server requires significant resources — Vaultwarden runs on a Raspberry Pi.

What You Need

  • A Linux server or Raspberry Pi that stays on
  • Docker and Docker Compose installed
  • A domain name pointing to your server
  • Port 443 open — Vaultwarden requires HTTPS

Deploy with Docker Compose

mkdir -p /opt/vaultwarden && cd /opt/vaultwarden
nano compose.yml
services:
  vaultwarden:
    image: vaultwarden/server:latest
    container_name: vaultwarden
    restart: unless-stopped
    environment:
      DOMAIN: "https://vault.yourdomain.com"
      SIGNUPS_ALLOWED: "true"      # set to false after creating your account
      ADMIN_TOKEN: ""              # generate one below
      LOG_LEVEL: "warn"
    volumes:
      - ./data:/data

  caddy:
    image: caddy:2
    container_name: caddy
    restart: unless-stopped
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./Caddyfile:/etc/caddy/Caddyfile
      - caddy_data:/data
    depends_on:
      - vaultwarden

volumes:
  caddy_data:
nano Caddyfile
vault.yourdomain.com {
    reverse_proxy vaultwarden:80
}

Generate an Admin Token

# Generate a secure token
openssl rand -base64 48

# Paste it into ADMIN_TOKEN in compose.yml
# Access the admin panel at https://vault.yourdomain.com/admin

Start Vaultwarden

docker compose up -d

# Check logs
docker compose logs -f vaultwarden

Caddy automatically gets a Let's Encrypt certificate for your domain. Give it a minute to provision.

Create Your Account

  1. Go to https://vault.yourdomain.com
  2. Click Create Account
  3. Use a strong master password — if you forget it, your vault is gone. There is no recovery without the master password.
  4. After creating your account, set SIGNUPS_ALLOWED: "false" in compose.yml and restart

Install Bitwarden Clients

Use any official Bitwarden app — they all work with Vaultwarden:

  • Browser extension: Chrome, Firefox, Safari, Edge — bitwarden.com/download
  • Desktop app: Windows, macOS, Linux
  • Mobile: iOS App Store, Google Play

In any client, go to Settings → Server URL and enter your Vaultwarden URL before logging in.

Enable 2FA

Account Settings → Security → Two-step Login

TOTP (authenticator app) and email 2FA work out of the box. YubiKey and FIDO2/WebAuthn require a Bitwarden Premium subscription — but Vaultwarden lets you enable these for free in the admin panel.

Admin Panel

https://vault.yourdomain.com/admin

From the admin panel you can invite users, manage organisations, see diagnostics, configure email (SMTP), and enable premium features like FIDO2 support.

Email (SMTP)

Configure SMTP so Vaultwarden can send verification emails and 2FA codes:

environment:
  SMTP_HOST: "smtp.gmail.com"
  SMTP_FROM: "vault@yourdomain.com"
  SMTP_PORT: "587"
  SMTP_SECURITY: "starttls"
  SMTP_USERNAME: "your@gmail.com"
  SMTP_PASSWORD: "your-app-password"

Backups

# Back up the data directory — this is your entire vault
tar czf vaultwarden-backup-$(date +%Y%m%d).tar.gz /opt/vaultwarden/data/

# Automate with cron
0 2 * * * tar czf /mnt/backup/vaultwarden-$(date +\%Y\%m\%d).tar.gz /opt/vaultwarden/data/

Update Vaultwarden

cd /opt/vaultwarden
docker compose pull
docker compose up -d
