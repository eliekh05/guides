Fix AirDrop Not Working

AirDrop uses both Wi-Fi and Bluetooth simultaneously. Either one being off or unavailable breaks it entirely.

Check the Basics First

  • Both devices must have Wi-Fi ON — even if you are not on a network
  • Both devices must have Bluetooth ON
  • Both devices must be within 9 metres (30 feet) of each other
  • Neither device should be in Airplane Mode
  • Personal Hotspot must be off on iPhones

Check AirDrop Visibility

On Mac: Finder → AirDrop in sidebar → set "Allow me to be discovered by" to Everyone for testing. Change back to Contacts Only afterwards.

On iPhone/iPad: Control Center → long-press the connectivity block → AirDrop → Everyone for 10 Minutes.

Restart Bluetooth and Wi-Fi

Turn Bluetooth off, wait 5 seconds, turn it back on. Do the same for Wi-Fi. Do this on both devices.

Restart the AirDrop Service on Mac

# Restart Bluetooth daemon
sudo pkill bluetoothd

# Restart mDNSResponder (handles device discovery)
sudo killall mDNSResponder

Check Firewall Settings

System Settings → Network → Firewall → Options → make sure Block all incoming connections is NOT checked. AirDrop needs incoming connections to receive files.

Sign Out and Back Into iCloud

AirDrop between your own Apple devices uses iCloud to verify identity. If iCloud is having issues, AirDrop between your own devices can fail. System Settings → Apple ID → Sign Out → Sign In.

Reset Network Settings on iPhone

If AirDrop is not working specifically from iPhone: Settings → General → Transfer or Reset iPhone → Reset → Reset Network Settings. This clears saved Wi-Fi passwords so have them ready.

macOS Ventura and Later — AirDrop Over Internet

macOS Ventura added AirDrop over the internet for transfers between your own Apple ID devices when they are out of Bluetooth range. This requires both devices to be signed into the same Apple ID and have Wi-Fi. If this is not working, the issue is usually iCloud connectivity — check apple.com/support/systemstatus.

Check for macOS/iOS Version Mismatch

Older iOS versions (before iOS 16) have known AirDrop issues with macOS Ventura and later. Update both devices to current versions before troubleshooting further.
