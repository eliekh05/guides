Fix Slow Mac Startup

A Mac that takes forever to boot usually has too many login items, a full or almost-full drive, or a background process that won't stop spinning. Here's how to diagnose and fix it.

How Long Is Normal?

  • Apple Silicon Mac with SSD: 10–20 seconds from power button to desktop
  • Intel Mac with SSD: 20–40 seconds
  • Intel Mac with spinning hard drive: 1–2 minutes (the drive is the bottleneck)

Check Login Items

Login items are apps that launch automatically at startup — each one adds startup time:

System Settings → General → Login Items & Extensions

Remove anything you don't need running at startup. Common culprits: Dropbox, Creative Cloud, Spotify, Steam, printer software, old apps you forgot about.

Check Startup Agents (Advanced)

Some apps add hidden startup agents that don't show in the Login Items list:

# List all startup agents
ls ~/Library/LaunchAgents/
ls /Library/LaunchAgents/
ls /Library/LaunchDaemons/

Delete .plist files for apps you've uninstalled — they keep loading even after the app is gone.

Free Up Disk Space

macOS needs roughly 10–15% free disk space to breathe. A nearly full drive causes dramatically slower performance including startup:

Apple menu → About This Mac → Storage

Delete large files, empty the Trash, and clear Downloads. Use ncdu (install with Homebrew) in the terminal to find what's taking up space:

sudo ncdu /

Rebuild Spotlight Index

A corrupted Spotlight index causes Spotlight to re-index at startup, hogging CPU and slowing things down:

# Remove and rebuild the index
sudo mdutil -E /
# macOS will rebuild overnight or when idle

Check What's Slow with Console

# View boot logs
log show --predicate 'eventMessage contains "boot"' --last boot | head -50

# Find slow startup items in Console.app
Open Console → search for "slow" or "timeout"

Reset NVRAM and SMC

Corrupted NVRAM can add several seconds to startup:

Intel NVRAM reset: Shut down → power on and hold Option+Command+P+R for 20 seconds.

Intel SMC reset: Shut down → hold Shift+Control+Option+Power for 7 seconds → release → power on.

Apple Silicon: Just restart — both reset automatically.

Run First Aid on the Startup Drive

Open Disk Utility → select Macintosh HD → click First Aid → Run

Filesystem errors force macOS to check and repair the drive on every boot, adding significant time.

Disable FileVault (Last Resort)

FileVault encrypts your drive and adds 2–5 seconds to startup time. If startup time matters more than encryption for your use case:

System Settings → Privacy & Security → FileVault → Turn Off FileVault

Decryption takes a few hours to complete in the background.

Check for Malware

Unexpected background processes at startup can be malware. Download Malwarebytes for Mac (free version is enough) and run a scan.
