Homebrew — Installing and Managing Packages on macOS

Homebrew is the package manager for macOS. It lets you install command-line tools, programming languages, databases, and GUI apps from the terminal — and keep them all updated in one command.

Install Homebrew

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

After installing on Apple Silicon, add Homebrew to your PATH:

echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"

Basic Commands

# Install a package
brew install wget
brew install git
brew install node

# Uninstall
brew uninstall wget

# Update Homebrew itself
brew update

# Upgrade all installed packages
brew upgrade

# Upgrade a specific package
brew upgrade git

# Search for a package
brew search python

# Get info about a package
brew info node

List What You Have Installed

# All installed packages
brew list

# Only top-level installs (not dependencies)
brew leaves

# Which packages are outdated
brew outdated

Install GUI Apps with Casks

Homebrew Cask installs macOS apps (.app bundles) — the same ones you'd normally download from a website:

# Install apps
brew install --cask firefox
brew install --cask visual-studio-code
brew install --cask rectangle
brew install --cask iterm2

# List installed casks
brew list --cask

# Uninstall a cask
brew uninstall --cask firefox

Install Specific Versions

# Search for available versions
brew search python@

# Install a specific version
brew install python@3.11
brew install node@18

# Link a version as the default
brew link python@3.11

Taps — Third-Party Repositories

# Add a tap (third-party repo)
brew tap hashicorp/tap
brew install hashicorp/tap/terraform

# List your taps
brew tap

# Remove a tap
brew untap hashicorp/tap

Clean Up Old Versions

# Remove old versions of installed packages
brew cleanup

# Remove everything unused (dependencies no longer needed)
brew autoremove

# See what cleanup would remove (dry run)
brew cleanup -n

Fix Problems

# Check for issues
brew doctor

# Fix permissions
sudo chown -R $(whoami) $(brew --prefix)/*

# Reinstall a broken package
brew reinstall wget

Brewfile — Save and Restore Your Setup

# Export your current setup to a Brewfile
brew bundle dump --file=~/Brewfile

# Install everything from a Brewfile (on a new Mac)
brew bundle install --file=~/Brewfile

A Brewfile is just a text file — commit it to git to keep your setup reproducible across machines.

Useful One-Liners

# Update, upgrade, and clean in one go
brew update && brew upgrade && brew cleanup

# Install multiple packages at once
brew install git wget curl jq fzf ripgrep
