macOS Safe Mode and Recovery Mode — When to Use Each

Safe Mode and Recovery Mode are two different troubleshooting environments. Knowing which to use and how to enter them saves time when your Mac has problems.

Safe Mode

Safe Mode boots macOS normally but disables third-party kernel extensions, login items, and startup agents. The desktop loads — you can use the Mac, just with minimal software.

Use Safe Mode when:

  • The Mac is slow or unstable and you suspect a third-party app or extension
  • An app crashes on launch
  • You want to run Disk Utility's First Aid while the system is running
  • You need to uninstall a problematic app that launches at startup

Enter Safe Mode

Apple Silicon (M1/M2/M3/M4):

  1. Shut down completely
  2. Press and hold the Power button until "Loading startup options" appears
  3. Select your startup disk
  4. Hold Shift and click Continue in Safe Mode

Intel Mac:

  1. Restart
  2. Immediately hold Shift until the login screen appears
  3. "Safe Boot" appears in the top right corner of the login screen

Safe Mode does a directory check and clears some caches on boot — it takes longer than normal.

Exit Safe Mode

Restart normally. No special steps needed.

Recovery Mode

Recovery Mode boots a separate minimal macOS environment from a recovery partition. The desktop does not load — you get a menu with tools.

Use Recovery Mode when:

  • macOS will not boot at all
  • You need to reinstall macOS
  • You need to run First Aid on the startup disk itself
  • You need to disable or enable SIP (System Integrity Protection)
  • You need to reset a forgotten login password
  • You need to restore from a Time Machine backup

Enter Recovery Mode

Apple Silicon:

  1. Shut down completely
  2. Press and hold the Power button until "Loading startup options" appears
  3. Click Options → Continue

Intel Mac:

  1. Restart
  2. Immediately hold Cmd+R
  3. Hold until the Apple logo or spinning globe appears

Recovery Mode Tools

  • Restore from Time Machine — restore your entire Mac from a backup
  • Reinstall macOS — clean install without erasing data, or full erase
  • Safari — limited web browsing (useful for downloading drivers or guides)
  • Disk Utility — repair disk errors, erase drives, manage volumes
  • Terminal — command line access, including resetpassword utility

Disable SIP in Recovery Mode

# In Recovery Mode → Utilities → Terminal
csrutil disable
reboot
# Re-enable SIP (do this after you are done)
csrutil enable
reboot

Reset Password in Recovery Mode

Recovery Mode → Utilities menu → Terminal:

resetpassword

A GUI tool opens to reset any user's password.

Internet Recovery

If the recovery partition is damaged, Intel Macs can boot from Apple's servers:

  • Cmd+Option+R — boot latest macOS available for your Mac
  • Cmd+Option+Shift+R — boot the macOS that came with your Mac

Internet Recovery requires a Wi-Fi connection and takes 15–30 minutes to download.

Apple Silicon Macs always use the on-device recovery — Internet Recovery is not needed.
