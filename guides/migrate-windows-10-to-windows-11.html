Migrate from Windows 10 to Windows 11

Windows 10 reached end of life on October 14, 2025. This guide covers upgrading to Windows 11 cleanly, including on hardware that does not officially meet the requirements.

Check Compatibility First

# Open PowerShell and run:
Get-TPMVersion

Or download the PC Health Check app from microsoft.com to get a detailed compatibility report.

Windows 11 requires:

  • TPM 2.0 (most PCs from 2017+ have this)
  • Secure Boot capable (check BIOS settings)
  • 64-bit CPU from the supported list (Intel 8th gen+, AMD Ryzen 2000+, Qualcomm Snapdragon 850+)
  • 4 GB RAM minimum, 8 GB recommended
  • 64 GB storage minimum

Enable TPM 2.0 in BIOS (If Needed)

Restart → enter BIOS (F2, F10, DEL, or F12 depending on manufacturer).

Look for:

  • Intel: Security → Intel Platform Trust Technology (PTT) → Enable
  • AMD: Security → AMD fTPM → Enable
  • Discrete TPM chip: Security → TPM Device → Enable

Enable Secure Boot while you are in BIOS (usually under Boot or Security tab).

Upgrade via Windows Update (Supported Hardware)

Settings → Windows Update → Check for updates

If Windows 11 is available for your device, it appears as a feature update. Click Download and Install. The process takes 30–90 minutes and reboots several times.

Upgrade via Installation Assistant (Supported Hardware)

If Windows Update does not offer the upgrade:

  1. Download Windows 11 Installation Assistant from https://microsoft.com/en-us/software-download/windows11
  2. Run it as Administrator
  3. Accept the terms and click Refresh
  4. The tool downloads Windows 11 and upgrades in place

Bypass Requirements for Unsupported Hardware

If your CPU is not on the supported list but you have TPM 2.0, use the registry bypass during setup:

  1. Download the Windows 11 ISO from microsoft.com
  2. Mount the ISO (double-click in Windows 10)
  3. Press Shift+F10 to open Command Prompt during setup
  4. Run:
reg add "HKLM\SYSTEM\Setup\MoSetup" /v AllowUpgradesWithUnsupportedTPMOrCPU /t REG_DWORD /d 1 /f
  1. Close Command Prompt and continue setup normally

What Gets Kept During Upgrade

  • All personal files (Documents, Downloads, Desktop, Pictures)
  • Installed applications
  • Settings and preferences

What Changes

  • Start menu moves to the center (you can move it back: Settings → Personalisation → Taskbar → Taskbar behaviours → Left)
  • Right-click context menu is condensed (click "Show more options" to get the full menu back)
  • Snap layouts appear when hovering over the maximize button
  • System tray icons are hidden by default
  • Android app support removed as of 2025

Roll Back to Windows 10 (Within 10 Days)

If something breaks, you can roll back within 10 days of the upgrade:

Settings → System → Recovery → Go back

After 10 days this option disappears.
