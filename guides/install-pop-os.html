Install Pop!_OS

Pop!_OS is a Linux distribution by System76. It has excellent Nvidia support out of the box, a clean GNOME-based desktop, and a tiling window manager (COSMIC) built in. Popular with developers and creators.

Download

Go to https://pop.system76.com and choose:

  • Intel/AMD — for Intel or AMD GPUs
  • NVIDIA — for Nvidia GPUs, includes proprietary drivers pre-installed

Flash with balenaEtcher or Ventoy.

Install

Pop!_OS uses its own installer. Boot from USB.

Clean Install: Select your disk, choose Erase and Install, set your username and password.

Dual Boot: Select Custom (Advanced), create partitions manually. Pop!_OS needs at minimum a FAT32 EFI partition (512 MB) and an ext4 or Btrfs root partition.

First Steps After Install

# Update everything
sudo apt update && sudo apt full-upgrade -y

# Pop!_OS has its own package manager for firmware and OS upgrades
sudo pop-upgrade release upgrade

Nvidia Setup (if using Nvidia ISO)

Drivers are pre-installed. Verify:

nvidia-smi
sudo prime-select query    # shows which GPU is active (intel or nvidia)

Switch between GPUs:

sudo prime-select nvidia    # use Nvidia GPU
sudo prime-select intel     # use integrated Intel GPU (saves battery)
sudo reboot

Install Software

# Via apt
sudo apt install git vim curl htop

# Via Flatpak (Flathub is pre-configured)
flatpak install flathub com.spotify.Client
flatpak install flathub com.discordapp.Discord
flatpak install flathub com.visualstudio.code

Pop!_Shop (the app store) includes both apt packages and Flatpaks in one interface.

COSMIC Tiling Window Manager

Pop!_OS 22.04 includes the COSMIC tiling extension for GNOME. Enable it:

Super+Y — toggle tiling mode on/off

ShortcutAction
Super+EnterOpen terminal
Super+/Launcher
Super+ArrowMove focus between windows
Super+Shift+ArrowMove window
Super+YToggle tiling
Super+MToggle maximize

Pop!_OS 24.04 — COSMIC Desktop

Pop!_OS 24.04 (released 2025) ships COSMIC — a completely new desktop environment written in Rust, replacing GNOME. It has a built-in tiling compositor, app library, and settings app. If you install 22.04 you can upgrade:

sudo pop-upgrade release upgrade

Fix Common Issues

No sound after install:

systemctl --user restart pipewire
systemctl --user restart wireplumber

Bluetooth not working:

sudo rfkill unblock bluetooth
sudo systemctl restart bluetooth

Screen tearing (Nvidia): Switch to Nvidia GPU with sudo prime-select nvidia and reboot.
