Install Windows 11 on Unsupported Hardware

Microsoft's official requirements block Windows 11 on older CPUs (Intel 7th gen and earlier, AMD Ryzen 1000 series) and machines without TPM 2.0. The registry bypass lets you install and run a fully functional Windows 11 on these machines.

Microsoft will still provide Windows 11 updates to machines installed this way. The main risk is Microsoft could add a check in a future update that blocks installation — this has not happened as of 2026 and Microsoft has said they will not remove functionality but may not guarantee support on unsupported hardware.

Method 1 — Registry Bypass During Setup (Upgrade from Windows 10)

  1. Download the Windows 11 ISO from https://microsoft.com/en-us/software-download/windows11
  2. Mount the ISO (double-click it in Windows 10)
  3. Open the mounted drive and run setup.exe
  4. When setup says "This PC doesn't meet the minimum requirements", press Shift+F10 to open Command Prompt
reg add "HKLM\SYSTEM\Setup\MoSetup" /v AllowUpgradesWithUnsupportedTPMOrCPU /t REG_DWORD /d 1 /f
  1. Close Command Prompt
  2. Go back and click the refresh/check button — it should now proceed

Method 2 — Rufus (Clean Install)

Rufus 3.19+ has built-in support for bypassing Windows 11 requirements when creating a bootable USB:

  1. Download Rufus from https://rufus.ie
  2. Select your USB drive and the Windows 11 ISO
  3. Click Start — Rufus asks about Windows customization
  4. Check Remove requirement for 4GB+ RAM, Secure Boot and TPM 2.0
  5. Optionally check Remove requirement for an online Microsoft account
  6. Click OK and create the USB
  7. Boot from USB and install normally

Method 3 — Registry Edit Before Running Setup

Add these registry keys on your Windows 10 machine before launching the installer:

# Open PowerShell as Administrator and run:
reg add "HKLM\SYSTEM\Setup\MoSetup" /v AllowUpgradesWithUnsupportedTPMOrCPU /t REG_DWORD /d 1 /f

reg add "HKLM\SYSTEM\Setup\LabConfig" /v BypassTPMCheck /t REG_DWORD /d 1 /f
reg add "HKLM\SYSTEM\Setup\LabConfig" /v BypassSecureBootCheck /t REG_DWORD /d 1 /f
reg add "HKLM\SYSTEM\Setup\LabConfig" /v BypassRAMCheck /t REG_DWORD /d 1 /f
reg add "HKLM\SYSTEM\Setup\LabConfig" /v BypassStorageCheck /t REG_DWORD /d 1 /f
reg add "HKLM\SYSTEM\Setup\LabConfig" /v BypassCPUCheck /t REG_DWORD /d 1 /f

Then run setup.exe from the mounted ISO.

Create a Local Account (Skip Microsoft Account)

During setup when asked to sign in to Microsoft account:

  1. Enter a fake email like no@no.com and any password
  2. Setup says "Something went wrong" — click Back
  3. Now the "Sign in with a Microsoft account" option is gone and you can create a local account

Or use Rufus as above and check the option to skip Microsoft account requirement.

Performance on Old Hardware

Windows 11 performance on unsupported hardware is generally fine. The system requirements are marketing decisions as much as technical ones. A machine that ran Windows 10 well will usually run Windows 11 equally well.

The one real concern is security: without TPM 2.0, BitLocker uses a less secure mode and some security features like Credential Guard may not work. For home use this is a reasonable trade-off.
