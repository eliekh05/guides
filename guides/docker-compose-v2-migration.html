Docker Compose V2 Migration

Docker Compose V1 (docker-compose as a separate Python tool) reached end of life in July 2023. V2 (docker compose as a Docker plugin) is now the standard. If your scripts or guides use docker-compose, they need updating.

The Key Difference

# V1 — separate binary, Python-based, EOL
docker-compose up -d

# V2 — Docker plugin, Go-based, current
docker compose up -d

The only syntactic change is removing the hyphen. V2 is backwards compatible with V1 docker-compose.yml files — your compose files do not need changes.

Check Your Version

docker compose version    # V2 — should show v2.x.x
docker-compose version    # V1 — if this works, you have the old one

Install Compose V2

# Ubuntu/Debian — install Docker's official package (includes V2)
sudo apt remove docker-compose    # remove V1 if present
sudo apt install docker-compose-plugin

# Or via Docker's official apt repo
sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
# Fedora/RHEL
sudo dnf install docker-compose-plugin
# Arch
sudo pacman -S docker-compose    # Arch ships V2 as docker-compose

Compatibility Shim (Optional)

If you have scripts you cannot update immediately, create a shim:

sudo ln -s /usr/libexec/docker/cli-plugins/docker-compose /usr/local/bin/docker-compose

This makes docker-compose call V2 — buys time to update scripts without breaking them.

What Changed in V2

Container naming — V1 used underscores (myproject_web_1), V2 uses hyphens (myproject-web-1). If you reference container names in scripts or other configs, update them.

# Check container names after migrating
docker ps --format "table {{.Names}}\t{{.Image}}\t{{.Status}}"

Profiles — V2 has better profile support for conditional service loading:

services:
  web:
    image: nginx
  debug-tools:
    image: nicolaka/netshoot
    profiles: ["debug"]    # only starts with --profile debug
docker compose --profile debug up

Watch mode — V2.22+ has a watch command for auto-syncing files during development:

docker compose watch

Update Scripts and CI/CD

# Find all docker-compose references in your project
grep -r "docker-compose" . --include="*.sh" --include="*.yml" --include="*.yaml" --include="Makefile"

# Replace with sed (careful — review before running)
sed -i 's/docker-compose/docker compose/g' your-script.sh

Common V2 Commands

docker compose up -d              # start in background
docker compose down               # stop and remove containers
docker compose down -v            # also remove volumes
docker compose logs -f            # follow logs
docker compose logs -f service    # follow specific service
docker compose ps                 # list containers
docker compose exec web bash      # shell into container
docker compose pull               # pull latest images
docker compose build --no-cache   # rebuild images
docker compose restart service    # restart one service
docker compose top                # show running processes
