Fix Nvidia Driver Issues on Linux

Nvidia on Linux has a reputation for being difficult. Most problems fall into a few categories — wrong driver version, module not loading, or Wayland compatibility issues.

Check Current Driver Status

# Check if Nvidia module is loaded
lsmod | grep nvidia

# Check GPU detection and driver version
nvidia-smi

# Check what driver package is installed
dpkg -l | grep nvidia        # Ubuntu/Debian
rpm -qa | grep nvidia        # Fedora/RHEL

Install Nvidia Drivers on Ubuntu/Debian

# Find recommended driver version
ubuntu-drivers devices

# Install automatically (recommended)
sudo ubuntu-drivers autoinstall

# Or install a specific version
sudo apt install nvidia-driver-560

sudo reboot

Install Nvidia Drivers on Fedora

# Enable RPM Fusion
sudo dnf install https://download1.rpmfusion.org/free/fedora/rpmfusion-free-release-$(rpm -E %fedora).noarch.rpm
sudo dnf install https://download1.rpmfusion.org/nonfree/fedora/rpmfusion-nonfree-release-$(rpm -E %fedora).noarch.rpm

# Install drivers
sudo dnf install akmod-nvidia xorg-x11-drv-nvidia-cuda

# Wait for kernel module to build (important — do not reboot yet)
sudo akmods --force
sudo dracut --force
sudo reboot

Install Nvidia Drivers on Arch

# For current kernel
sudo pacman -S nvidia nvidia-utils nvidia-settings

# For LTS kernel
sudo pacman -S nvidia-lts

# Rebuild initramfs
sudo mkinitcpio -P
sudo reboot

Fix Black Screen After Installing Drivers

Boot to TTY: at login screen press Ctrl+Alt+F2.

# Check for driver errors
journalctl -b | grep -i nvidia | tail -30

# Check Xorg logs
cat /var/log/Xorg.0.log | grep -i "(EE)"

Common fix — remove conflicting nouveau driver:

# Blacklist nouveau
echo "blacklist nouveau" | sudo tee /etc/modprobe.d/blacklist-nouveau.conf
echo "options nouveau modeset=0" | sudo tee -a /etc/modprobe.d/blacklist-nouveau.conf
sudo update-initramfs -u    # Ubuntu/Debian
sudo dracut --force          # Fedora
sudo reboot

Nvidia on Wayland

Nvidia Wayland support improved significantly with driver version 555+ (released 2024). If you are on an older driver, Wayland may not work properly.

# Check driver version — need 555+ for good Wayland support
nvidia-smi | grep "Driver Version"

# Enable DRM kernel mode setting (required for Wayland)
sudo nano /etc/modprobe.d/nvidia.conf
options nvidia-drm modeset=1 fbdev=1
sudo update-initramfs -u    # Ubuntu/Debian
sudo dracut --force          # Fedora
sudo reboot

Fix Tearing on X11

sudo nano /etc/X11/xorg.conf.d/20-nvidia.conf
Section "Device"
    Identifier "Nvidia Card"
    Driver "nvidia"
    Option "NoLogo" "true"
    Option "TripleBuffer" "true"
    Option "ForceFullCompositionPipeline" "true"
EndSection

Switch Between Nvidia and Integrated GPU (Laptops)

# Install nvidia-prime
sudo apt install nvidia-prime    # Ubuntu/Debian

# Use Nvidia GPU
sudo prime-select nvidia

# Use integrated GPU (Intel/AMD — saves battery)
sudo prime-select intel

sudo reboot

Check DKMS Module Status After Kernel Update

# Check if Nvidia module built for current kernel
dkms status

# Rebuild if missing
sudo dkms autoinstall
sudo update-initramfs -u
sudo reboot
