Set Up SSH Keys for GitHub

SSH keys let you push and pull from GitHub without entering your password every time. GitHub removed password authentication for Git operations in 2021 — SSH keys or personal access tokens are now required.

Check for Existing SSH Keys

ls -la ~/.ssh

If you see id_ed25519 and id_ed25519.pub (or id_rsa and id_rsa.pub), you already have keys. Skip to the "Add Key to GitHub" section.

Generate a New SSH Key

# Ed25519 is the recommended algorithm (faster and more secure than RSA)
ssh-keygen -t ed25519 -C "your_email@example.com"

When prompted:

  • File location — press Enter to accept default (~/.ssh/id_ed25519)
  • Passphrase — set one for security, or press Enter for no passphrase

Add the Key to the SSH Agent

# Start the agent
eval "$(ssh-agent -s)"

# Add your key
ssh-add ~/.ssh/id_ed25519

On macOS, add to ~/.ssh/config so it loads automatically:

Host github.com
  AddKeysToAgent yes
  UseKeychain yes
  IdentityFile ~/.ssh/id_ed25519

Add the Public Key to GitHub

# Copy the public key to clipboard
cat ~/.ssh/id_ed25519.pub    # copy this output

# macOS shortcut
pbcopy < ~/.ssh/id_ed25519.pub

# Linux with xclip
xclip -selection clipboard < ~/.ssh/id_ed25519.pub
  1. Go to https://github.com/settings/keys
  2. Click New SSH key
  3. Give it a title (e.g. "MacBook Pro" or "Work laptop")
  4. Paste the public key
  5. Click Add SSH key

Test the Connection

ssh -T git@github.com

Expected output:

Hi username! You've successfully authenticated, but GitHub does not provide shell access.

Use SSH Instead of HTTPS for Repos

# Clone with SSH (use this format going forward)
git clone git@github.com:username/repo.git

# Change an existing repo from HTTPS to SSH
git remote -v                                          # check current
git remote set-url origin git@github.com:username/repo.git
git remote -v                                          # verify

Multiple GitHub Accounts

If you have a personal and work GitHub account, generate a second key and configure SSH to use different keys per host:

# Generate second key
ssh-keygen -t ed25519 -C "work@company.com" -f ~/.ssh/id_ed25519_work
# ~/.ssh/config
Host github.com
  HostName github.com
  User git
  IdentityFile ~/.ssh/id_ed25519

Host github-work
  HostName github.com
  User git
  IdentityFile ~/.ssh/id_ed25519_work
# Clone using the work alias
git clone git@github-work:company/repo.git

Fix Common Errors

Permission denied (publickey) — key not added to agent or not added to GitHub. Run ssh-add ~/.ssh/id_ed25519 and verify the public key is in GitHub settings.

Bad permissions on ~/.ssh/config — SSH requires strict permissions:

chmod 600 ~/.ssh/config
chmod 700 ~/.ssh/
chmod 600 ~/.ssh/id_ed25519
