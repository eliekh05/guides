Install Ubuntu Server

Ubuntu Server is one of the most widely used Linux distributions for hosting, self-hosting, and cloud deployments. It has no GUI by default — you manage everything through the terminal.

Download

Get the latest LTS (Long Term Support) release from ubuntu.com/download/server. LTS versions get 5 years of security updates. As of 2026, that's Ubuntu 24.04 LTS (Noble Numbat).

Create Bootable USB

# Linux/macOS — find your USB drive first
lsblk    # or diskutil list on macOS

# Write the ISO (replace sdX with your USB drive)
sudo dd if=ubuntu-24.04-server.iso of=/dev/sdX bs=4M status=progress oflag=sync

On Windows, use Rufus (rufus.ie) — select the ISO, pick your USB, click Start.

Installation Steps

  1. Boot from USB — enter BIOS/UEFI (F2, F12, Del, or Esc depending on your machine) and set USB as first boot device
  2. Select language
  3. Choose keyboard layout
  4. Select "Ubuntu Server" (not minimized) on the type screen
  5. Configure network — DHCP is fine for most setups; set a static IP if this is a permanent server
  6. Leave proxy blank unless you have one
  7. Accept the default Ubuntu mirror
  8. Configure storage — "Use entire disk" with LVM is the safe default
  9. Confirm destructive action — this wipes the drive
  10. Set your name, server name, username, and password
  11. Install OpenSSH server — yes, do this so you can connect remotely
  12. Skip snaps for now
  13. Wait for install to complete, then remove USB and reboot

First Login and Update

# Log in with your username and password

# Update everything immediately
sudo apt update && sudo apt upgrade -y

# Reboot if kernel was updated
sudo reboot

Connect via SSH

# Find your server's IP address
ip a | grep "inet " | grep -v 127

# From another machine
ssh youruser@192.168.1.100

Set a Static IP

sudo nano /etc/netplan/00-installer-config.yaml
network:
  version: 2
  ethernets:
    ens3:                        # replace with your interface name
      dhcp4: no
      addresses:
        - 192.168.1.50/24
      routes:
        - to: default
          via: 192.168.1.1
      nameservers:
        addresses: [1.1.1.1, 8.8.8.8]
sudo netplan apply

Configure UFW Firewall

# Enable firewall and allow SSH
sudo ufw allow OpenSSH
sudo ufw enable
sudo ufw status

Useful First Steps

# Set hostname
sudo hostnamectl set-hostname myserver

# Set timezone
sudo timedatectl set-timezone America/New_York
timedatectl    # verify

# Install useful tools
sudo apt install -y curl wget git htop ncdu unzip build-essential

# Check system info
uname -a
lsb_release -a
free -h
df -h

Automatic Security Updates

sudo apt install unattended-upgrades -y
sudo dpkg-reconfigure --priority=low unattended-upgrades
# Choose "Yes" to enable automatic security updates
