Fix App Crashing on macOS

When an app crashes on macOS the system generates a crash report with the exact cause. Reading it is the fastest way to understand what is wrong.

Find the Crash Report

open ~/Library/Logs/DiagnosticReports/

Or: Console app → Crash Reports in the sidebar. Look for a file named after the app with a recent timestamp.

The crash report shows the exception type, the thread that crashed, and a full stack trace. The most useful lines are near the top:

Exception Type:  EXC_CRASH (SIGABRT)
Exception Codes: 0x0000000000000000
Termination Reason: Namespace SIGNAL, Code 6 Abort trap: 6

Common Crash Types and Fixes

EXC_CRASH / SIGABRT — the app called abort() deliberately, usually because of a failed assertion. Often caused by a corrupted preference file or incompatible plugin.

EXC_BAD_ACCESS / SIGSEGV — memory access violation. Usually a bug in the app. Update the app — if the crash persists, report it to the developer with the crash log.

EXC_BAD_INSTRUCTION — illegal CPU instruction. Often seen after a partial update or corrupted app bundle. Reinstall the app.

Delete App Preferences

Corrupted preferences are the most common fixable cause of crashes.

# Replace AppName with the app's bundle identifier
# Find it:
defaults find AppName | grep "Domain" | head -5

# Delete preferences
defaults delete com.developer.appname

# Or delete the plist file directly
rm ~/Library/Preferences/com.developer.appname.plist

Delete App Support Files

rm -rf ~/Library/Application\ Support/AppName/

The app will recreate these on next launch with defaults.

Delete App Cache

rm -rf ~/Library/Caches/com.developer.appname/

Reinstall the App Cleanly

Dragging an app to Trash does not remove its preferences, caches, or support files. Use AppCleaner (free) to find and remove all associated files before reinstalling.

Check for Incompatible Extensions or Plugins

Some apps (browsers, creative tools, IDEs) load third-party plugins at startup. If the app crashes immediately on launch, try starting it without plugins.

  • Safari: hold Shift while launching to disable extensions
  • VS Code: code --disable-extensions
  • Chrome: /Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome --disable-extensions

Check Disk Health

If multiple apps are crashing, the issue may be disk errors rather than the apps themselves.

diskutil verifyVolume /

If errors are found, boot into Recovery Mode (hold Cmd+R on Intel or power button on Apple Silicon) → Disk Utility → First Aid.

Report the Crash to the Developer

If nothing fixes it, the crash is a bug in the app. Find the crash report file in ~/Library/Logs/DiagnosticReports/, attach it to a bug report to the developer. A crash log is far more useful to them than a description.
