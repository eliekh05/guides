Managing Processes and Jobs on Linux

Understanding how to view, control, and kill processes is fundamental to Linux administration.

View Running Processes

# Snapshot of all processes
ps aux

# Filter by name
ps aux | grep nginx

# Interactive process viewer (better than ps)
top
htop    # install with: sudo apt install htop

top / htop Keys

KeyAction
kKill process (enter PID)
rRenice (change priority)
fFilter/sort columns
uFilter by user
qQuit
MSort by memory
PSort by CPU

Find a Process

# Find PID by name
pgrep nginx
pgrep -a nginx    # show full command

# Find and show process tree
pstree -p

# Find what is using a port
sudo ss -tlnp | grep :80
sudo lsof -i :80

Kill Processes

# Kill by PID
kill PID           # SIGTERM — polite request to stop
kill -9 PID        # SIGKILL — force kill immediately

# Kill by name
pkill nginx        # kill all processes named nginx
killall nginx      # same

# Kill all processes matching pattern
pkill -f "python script.py"

Background and Foreground Jobs

# Run a command in the background
./long-script.sh &

# List background jobs
jobs

# Bring a job to foreground
fg %1       # job number 1
fg          # most recent job

# Send running command to background
# Press Ctrl+Z to pause, then:
bg          # resume in background

nohup — Keep Running After Logout

# Run command that survives SSH disconnection
nohup ./script.sh &

# Output goes to nohup.out by default
nohup ./script.sh > /var/log/script.log 2>&1 &

# Check it is running
jobs
ps aux | grep script.sh

Process Priority (nice)

# Run with lower priority (nicer to other processes)
nice -n 10 ./cpu-heavy-script.sh

# Run with higher priority (requires root)
sudo nice -n -10 ./important-script.sh

# Change priority of running process
renice +10 -p PID       # lower priority
sudo renice -5 -p PID   # higher priority

systemd Service Processes

# Check all processes for a service
systemctl status nginx

# See process tree for a service
systemd-cgls /system.slice/nginx.service

Watch a Process

# Watch memory and CPU of a specific process
watch -n 1 'ps -p PID -o pid,pcpu,pmem,cmd'

# Watch with htop filtered to one process
htop -p PID

Zombie Processes

A zombie process (Z in ps output) is a finished process whose parent has not collected its exit code. They cannot be killed directly — kill the parent process instead:

# Find zombies
ps aux | grep 'Z'

# Find the parent of a zombie
ps -o ppid= -p ZOMBIE_PID

# Kill the parent
kill PARENT_PID
